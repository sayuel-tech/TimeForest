# 检查与证据入口

本页只维护检查入口和证据解释；当前进度统一见[维护基线](../maintenance-baseline.md)，R1实际接入与必要检查见[接入记录](site-experience.md)。

R1接入后的索引为17个专题、7个模式、139个前端文件、18件美术资产。它仍只证明路径、导入、覆盖和资源指纹，不证明交互或审美。最初“16专题／136文件、只做文档盘点”的结论属于接入前历史，不能继续作为当前状态。

前一开发任务已使用原站ES Modules及真实临时Flask路由进行相关页面、保存、绑定、剪辑和图片画布检查；原型包的模拟检查不并入本项目通过数。完整环境、范围、局限和外部本地证据目录在接入记录。此次进度整理只复核文档及索引，不重跑业务测试。

后续前端变化按既有要求运行 node tools/check_experience_contract.mjs；视觉相关运行 node tools/check_ui_design.mjs。它们的通过不等于用户认可，原五模式 baseline 不直接作为当前缺陷清单。

页面卡列出定向测试与 fixture。执行前阅读 fixture 的临时数据、假 API、真实隔离 API 边界；尤其图片可选 --real-image-api 不等于生产 API。全站项目图、媒体、数据库、密钥不用于写入验证。

维护工具的机械覆盖包括当前 static/studio 的 JS、顶层 styles CSS、static/index.html、styles tokens 和索引列出的字体 CSS；字体分片仅按清单计数，不逐个当成页面实现。动态导入/业务事件的全部可达性不在静态分析保证内。

初始盘点使用的八张历史图片见 audit/evidence；R1隔离页面截图属于另一批证据。用户已确认原站美术和新包布局方向，但没有确认最终实现的整体体验。未验证生产页面、真实生成或性能；进度文档维护不启动生产服务。
