# GitHub 分享与发行维护

当前公开仓库为 [sayuel-tech/TimeForest](https://github.com/sayuel-tech/TimeForest)。v6.3.32 沿用 v6.3.20 的公开 main 历史，配套工作流与模型清单改为 GitHub Release 附件；安装入口见[分发说明](release-distribution.md)。

常规开发不自动授权提交、推送或发行。发布须先核对用户授权及目标远程，保留原作者许可、第三方来源与现有公开历史，不把含个人维护资料的原始私有历史合入本仓库。

公开源码排除真实配置、凭据、模型权重、项目媒体、数据库、节点扫描缓存、用户资产与提示词库及补记快照。配套包只包含已审阅的来源图、通用输入 API 示例、模型名称、许可和校验说明。库备份及自定义目录应位于仓库外，不作为示例。

用户已授权项目介绍使用 docs/images 中的四张截图；其他素材不能自动沿用授权。介绍维护在[中文介绍](project-introduction.zh-CN.md)，公开 README 同步介绍与安装入口。截图中的单次用时不构成性能承诺。

发布前检查实际文件、暂存内容、离线配套组合和相关隔离回归；工具 tools/check_repository.py 检查暂存文件，不能代替人工审核。源码和 tag 同批推送，Release 附件与链接同版交付。原始工作流与 ZIP 不混入源码树，以免安装后误提交。
