# 资产共同体验与来源追溯 · 本地6.3.26

本轮落实用户批准的资产管理完善方案，维护既有资产库和五模式，不替换存储或生成流程。资产身份、不可变版本、项目执行副本、资料不进入创作正文、幂等使用与入库、三类回收站继续使用现行实现。

## 用户操作与实际改动

- 资产详情增加“来源与制作记录”：来源项目显示当前名称、模式及可用跳转；已有制作时名称不同则另行显示。已移除项目导向项目回收站，不存在时显示原记录名称/ID且不造跳转。任务、片段、运行ID按记录显示。
- 来源项目与使用过的项目分开。历史refs仍是原结构；API另加reference_projects提供项目名称/可用状态，不能把历史登记当作当前仍使用。生成来源不从refs或文件名推断。
- 参数默认折叠；读取该媒体固定版本的真实记录。图片按当前工具精选字段展示保存值与实际种子，视频保留既有运行/内部任务解析。无记录不读项目当前参数或默认值；原API图不用于猜字段。图片采样分组与图片制作参数共用定义，视频按视频分组。
- 各模式公共资产选择器增加“预览与来源”。图片/视频/声音在原选择器内预览，展开不选用、不导入；选择固定在列表所显示的版本，库中随后更新不暗换版本。多选取消返回空，不提交项目。
- 原三视频参考卡、换人源视频/角色入口、图片A/B、接续原视频/参考卡提供“查看库内素材与来源”，链接包含固定version/media。资料没有完整身份时不造入口。详情支持media参数选择确切媒体。
- 派生记录按parent.asset/version/media/hash向上追溯，最多16层，循环/缺失/不匹配明确停止，不改写旧记录。当前媒体没有参数时不借父资产参数填充。便携包没有可验证本地项目身份时不把包内旧ID链接到本机项目。
- 续接显示运行快照中的上一生成记录ID；合成记录按保存的parts或manifest.selected显示实际顺序。不以今天的轨道顺序解释历史成片，不改变P1→P11→P111的生成依赖。
- 来源界面读取失败保留原始错误与重读入口。返回/切换媒体后迟到响应不覆盖新界面，编辑资料不改制作记录。

## 接口与兼容

GET /api/v5/library/assets/<id>/origin?version=<固定版本>&media=<媒体> 返回version=1、chain、parameters、prompt、parts及必要notice。缺确切身份拒绝；版本和媒体都按所指资产验证。只读，无表变更、无历史回填。

详情API增加asset_origin_version=1和reference_projects；references保持旧的project/version数组结构，避免破坏既有调用方。只有展开选择器预览才请求来源，不为整个列表递归扫描。详情当前媒体更换后重新读其固定来源。

本轮含后端功能，磁盘完成不等于旧进程已加载。保存编辑、处理完活动任务后，通过既有菜单重启导演台并刷新页面。不要求重启ComfyUI；本轮没有自动重启生产服务。

## 后续新增功能准入

新模式或普通功能均需登记assetSelection、assetOrigins、assetUsage、assetCollection四个公共入口及assetLifecycle场景。声明可接收的媒体、目标位置、用途、固定版本、成功登记点、确切输出身份、来源与回收入口；不适用必须给业务依据。新增模式不能扩大历史baseline豁免。

assetLifecycle验收至少包括：预览不导入、取消无项目写入、成功后登记、库版本变化不暗换输入、生成结果入库/重开去重、来源项目/派生关系、缺失原项目、移除恢复保留副本，以及资料变更不进入生成正文。沿用原九类共同场景，新增资产专项成为第十类。未安装Git hook或CI，不能宣称自动强制执行。
