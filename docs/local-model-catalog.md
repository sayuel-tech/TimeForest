# 本地模型目录与自由选型

本地文件扫描适用于当前三个原视频模式、图片资产创作和视频接续；共用 `generation/local_models.py`，视频入口为 `Recipes.catalog()`，图片入口为 `image_studio/service.py::catalog()`。6.2.4 是视频接入该能力的历史时间点；图片在 V4 阶段 B 接入。当前网站状态统一见 [维护基线](maintenance-baseline.md)。正常兼容模型/LoRA 更新是放文件、刷新、选择，不要求逐模型登记、发版或生成认证。

## 页面行为

刷新网页后，项目参数目录重新扫描本地文件。制作参数中的“刷新本地模型列表”也可更新，无需连接或启动 ComfyUI。扫描只读取文件名，不加载权重。

视频底模、文本编码器、视频/音频 VAE、三个 LoRA 槽、官方加速 LoRA，以及图片底模、图文编码器、图片 VAE 和编辑 LoRA 均使用对应目录。移除文件后不再作为普通候选；已有项目或草稿仍保留该选项并标记目录未发现。五模式的底模、编码器、VAE、加速/普通LoRA统一使用 `ui/model-selector.js`：下拉展开完整目录，不以当前文件名过滤；“手动填写文件名”折叠区保留完整相对路径。目录外的当前值继续保留并提示，输入、选择、刷新均不自动替换模型。不以文件名家族作为普通模型选择的拒绝条件；目录中的 model_families 仍可作内部能力描述，不是文件许可表。既有工作流结构约束见 [参数映射](frontend/parameter-map.md)。

ComfyUI 提交验证失败及执行错误保留在项目错误提示和本次运行记录。节点结构、必要输入、时长和数字范围检查仍有效。上传声音导致工作流缺少音频入口时，仍按原业务要求展示工作流变更确认。此处与模型文件兼容性判断分开。

## 配置与扫描

默认以配置 comfy_input_dir 的父目录为 ComfyUI 基础目录；与输入路径一样，相对路径以网站项目根目录为基准。可在 config.json 中覆盖：

- comfy_base_dir：ComfyUI 基础目录。
- comfy_models_dir：模型目录，绝对路径或相对 ComfyUI 基础目录。
- comfy_extra_model_paths：额外 YAML 配置路径数组，支持 ComfyUI 的 base_path 和多行目录语法。

自动读取基础目录内 extra_model_paths.yaml、extra_models_config.yaml；Windows 桌面版 APPDATA/ComfyUI/extra_models_config.yaml 仅在所属基础目录匹配时自动读取。YAML 采用 PyYAML safe_load，不执行配置代码。目录解析和文件扫描放在独立 generation/local_models.py 中。

底模合并 unet 与 diffusion_models；编码器合并 text_encoders 与 clip；VAE 使用 vae；LoRA 使用 loras。支持当前标准加载器的权重扩展名，保留子目录相对路径。自定义加载器专属格式不自动切换节点；若以后增加这种工作流，应同时增加对应目录与加载器契约。

## 图片文件目录与节点声明

当图片引擎地址为 localhost／回环地址时，`GET /api/v5/image-projects/catalog` 通过现有 `LocalModels.scan()` 扫描文件列表，无需请求引擎；底模、编码器、VAE、LoRA 分别投影为 `choices.unet/clip/vae/lora`。`local_models` 提供来源、成功扫描／保留缓存时间、目录及读取错误。部分扫描失败时合并先前成功列表，完整失败时保留会话中上次成功目录；不会覆盖任务模型选择。

`POST /api/v5/image-projects/catalog/sync` 是单独的在线“同步节点能力”，读取 `/object_info`，将声明与引擎地址写入 `image-catalog.json`。`node_catalog` 单独给出来源、上次成功同步时间、本次错误及 `error_kind`；缓存读写或声明格式错误按网站操作显示，实际连接和引擎错误保留其类型，不统一猜成网络故障。同步失败保留匹配当前引擎的原缓存和参数。节点缺失提示不等于权重兼容性认证，普通本地文件刷新不以该动作作为前置步骤。

远程引擎不扫描本机目录，也不假装能够直接扫描远程文件。普通刷新只读取与当前引擎地址一致的节点缓存；远程新文件需在对应引擎目录放入，再显式同步在线声明。旧缓存未记录地址或地址不匹配时不混用，页面说明来源缺失及按需同步。模型选择仍保留，用户据真实错误决定调整。

制作参数刷新仅更新目录，保留弹窗临时编辑、外层任务草稿和画布标注；失败提供摘要及原始反馈。字段呈现与保存语义见[参数交互契约](frontend/parameter-and-interaction-contract.md)。阶段 B 相关检查使用隔离假文件和模拟节点反馈，不据此声称本机所有模型、任意路径分隔写法或模型组合已验证；真实生成与用户体验状态见维护基线。

目录 API 同时提供 `parameter_contract_version=1` 和四工具精选参数描述。图片进入工作区及刷新时由 `core/image-catalog.js` 校验该真实返回；旧后台缺描述时显示网站版本不一致，刷新失败保留旧目录和编辑，不以空参数表继续。保存已有编辑后重启网站服务并刷新即可重新读取接口，无需为此启动或升级 ComfyUI。
