# 素材包跨库来源 · 本地6.3.31

2026-09-09，接续资产管理三阶段计划。本批完成此前待办的外部素材包显式身份映射，保留此前来源定位、五模式添加/管理/入库与本机上下游查询。

## 实际交付

- 便携素材包增加独立“保留来源关系（仅恢复包内素材）”选项，默认开启。已有工作流资料选项保留；不带工作流也可保留已确认资产关系。只打包用户已选资产及明确勾选的绑定，不自动收集上游文件。
- 新导出使用格式2，每项媒体记录固定来源asset/version/media/hash及包内/包外状态。站点复用公共AssetLineage读取实际记录；独立Library调用只提取直接固定引用，不能读项目的部分明确标不完整。
- 导入先校验包内版本、媒体和摘要声明，及来源与绑定共同构成的依赖图；不允许循环。恢复为接收库独立身份，包内关系改指向接收库固定版本。文件哈希沿既有导入检查；不把同哈希视为生成归属证明。
- 导入回执同时保存首次资产和版本。重复导入、部分失败后重试不悄悄引用后来编辑的版本，也不重置编辑资料；原绑定使用同一固定版本规则。未随包提供的上游显示外部记录，外部项目/候选不凭相同编号自动关联本机。
- 来源与制作记录、只读参数、固定版本跳转和库内下游继续复用原公共组件；没有另造包专属来源页。旧格式1继续读取，旧导入残留的每媒体原始来源也受根portable_pack边界保护。图片参数有界解开包记录后展示原保存值，不能读当前设置补齐。
- 导出预览增加代次检查：勾选变化、关闭或取消读取后，迟到预览不能启用旧导出。预览响应声明pack_lineage_version=1；旧后台缺能力时明确提示重启，不静默导出旧格式。

包内关系表示“清单声明且固定媒体摘要可核对”，不表示经签名认证的作者身份。没有把外部项目或生成历史迁移进本机；未提供/未记录的来源仍是边界。再次导出可以转移当前库内已映射关系，不跨包凭编号合并。
