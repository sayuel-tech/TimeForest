## 设计流程（当前不可用）

方案迭代已更正业务顺序：无段落层级，资产需求先由LLM分析并形成绑定卡片；确认完整资产剧本后才切分镜，再在分镜下切片段。跨页目录、第三页上资产下剧本、第二/四/五页沟通输出版式及全剧/分镜/片段来源规则见[现行纠偏方案](product/creation-experience-correction.md)。上述体验本轮已接通，准确实现与检查范围以本轮交付说明为准。

补图入口更新（2026-09-09）：“去图片模式补图”仅询问保存或不保存当前草稿，然后进入空白图片任务；素材和制作指令在图片模式填写，不再弹出额外表单。关闭确认框保留输入，保存或创建失败不放行。新任务复用原handoff关联已保存的项目起点，空指令、无预带参考、用途为构图；不保存只放弃未保存正文，仍记录补图关联。旧分镜/片段补图关联与原回填保护保留。下述补图支持能力不代表入口仍要求先填指令。

剧本固定五页：故事起点、剧本创作、资产落实、分镜设计、片段 Prompt。前两层可人工编辑，云端服务未配置也能保存未完成稿。AI 返回先进入候选，用户核对并应用后才改正文；待补充、截断、无效引用和过期依据不会覆盖当前稿。局部改写保留分镜／片段身份及其他内容。旧blocks只作全文兼容承载，不形成段落业务目录。

参考资料与正式正文分开。项目、分镜、片段的绑定依次覆盖，`inherit` 沿用上层；可绑定固定版本、仅用文字、待落实或停用。补图交给原图片模式的普通文生图/单图/双图任务，网站不代点生成。结果入库后，从剧本选择固定版本，先比较，再明确作为备选或当前视觉参考。当前 H3 适配把起始/结束/构图图作为参考图片输入，不宣称强制首尾帧或尚未实现的控制节点。

第四、五页沿用纵向分镜—片段树；Prompt 支持完整正文和原 H3 结构化编译。可检查实际正文、Picture/Audio 编号及上游声画尾部槽。选定、确认好的片段或未完成剧本都可导入电影。未完成 Prompt 会在电影检查时明确阻止提交，不暗中补写。

电影只有片段生成、剪辑拼接两页。生成页只读来源正文，在原公共制作参数中调整本片段参数；需要改剧本时返回准确来源。跳舞与官方两条原 H3 路线各有独立生成/外部声画尾部、完整/结构化正文适配。单段超出合法帧预算时返回剧本拆分，不自动拆段。准备冻结精确 Prompt、参数、种子、输入版本、工作流摘要和上游结果，再提交一次。

B 续接 A02 后，后来改选 A04 不会改变 B 或其上游范围。查看历史候选、采用新候选、入库和修改剪辑是独立动作。创建剪辑时按生成页顺序放入采用结果；之后生成页的变化必须显式处理，替换保留原顺序与裁切区间，范围超出新结果时拒绝并请用户调整。

剪辑是横向按时长比例显示的片段轴，支持拖动/前后移、纳入/排除、分:秒.毫秒输入（仍按整数毫秒保存）、主播放器位置取点和连续预览。操作与生成关系在轴下方。来源返回记录原片段、候选、页面、缩放与横向位置；未找到指定候选不替换为最新结果。生成上游与实际相邻片段或裁切边界不一致时提示接点变化，导出前需明确接受。导出保留声音、无声片段补静音，不生成字幕。

## 配置与真实调用边界

初始云端配置仅 DeepSeek Chat，默认未启用、无凭据。模型 ID 为 `deepseek-v4.1-flash-expires-on-0910`，可编辑。服务到期/拒绝/网络状态不明会返回错误，保留内容，不自动改模、重发或格式修复。图片附件需用户显式勾选，并把服务视觉能力设为已确认支持；网站没有以测试推断该临时模型的视觉能力。

配置使用原 StudioStore defaults；凭据单独写在网站数据目录 `credentials`，不进入项目/资产/Prompt/配套包。云端并发由 `authoring_cloud_workers` 控制，默认 2，复用原 JobManager cloud 通道。GPU 和媒体通道沿用原机制。LM Studio 的表示与未来接入文档在配套中；没有本地发现、调用、启动停止、卸载或 GPU 调度实现。

服务重启只标记新模式未完任务的中断/待确认状态，不恢复旧队列。电影只核对明确的原引擎编号；查询恢复不重新提交。结束等待保留原记录，不能证明远端已经停止。云端停止是停止接收，已开始的远端请求可能仍执行。

## 公共机制与资产

项目、资产、Prompt、任务和回收站均使用原系统。项目只扩展原 JSON 内容版本，不迁移数据库。公共页头/步骤/三栏、底栏、参数弹窗与字段、模型列表、取消/应用/保存、计时、错误、素材用途、候选与播放器继续使用原组件。两个模式控制自己的写作对象/来源包/剪辑业务，不修改原五模式默认生成语义。

文本候选与电影候选的移除进入原“生成移除的”回收分类，恢复不自动选用/生成。已采用记录受保护，原件和已有引用保留。电影素材引用登记原 usage；入库走原幂等 ingest。源项目跳转、实际参数/Prompt、固定参考及上游候选派生链、已入库和项目内生成结果反查均接到原资产模块。来源缺失不读当前草稿补齐；素材包按原固定版本映射，外部项目身份不变成本机项目。
