## E0 定点映射

| 链路 | 复用与必要扩展 |
|---|---|
| 项目创建、列表、保存、回收 | StudioStore 原 projects JSON/revision；studio.py 分派 authoring/movie，不另建项目库 |
| 页面与草稿保护 | bootstrap 的 session/dirty/working/dispose；workspace-chrome、workbench、workspace-actions、choice-dialog |
| AI 请求与候选 | 新 h3ui/creation：任务上下文、固定响应、显式应用；既有 JobManager 与任务中心增加业务投影 |
| 资产与提示词 | 原 asset_library 和 prompt_library；新模式固定引用和正式正文捕获 |
| H3 执行 | 原 Recipes、输入编译、Comfy、媒体末端；电影独立采用策略，不复用自动 selected/下游清选 |
| 成片 | 原媒体处理和播放器；电影专属横轴、区间、来源与更新事务 |
| 配套 | h3ui/creation/resources 保存当前模板/合同/无密钥配置；不把执行计划发给 LLM |

前端公共层只增加必要适配，专属树与横轴分别承担身份/选择和剪辑业务。未修改原 studio_recipes 默认参数。已核对入口和既有工作树差异，原 context check 通过。
