# 全站字体与布局检查

本轮是临时数据下的实际前端页面检查，非真实生成。各JSON保存逐项结果：

- workspaces：七模式23个步骤页、各模式窄屏首页、14个参数宽窄场景，共44项；其中参数样式最后调整后以settings的14项复查为准，不重复计成功数。
- general：首页、项目档案、资产处理任务/存储/分类/回收站/详情、全局任务，1920/760窗口16项。
- libraries：资产/提示词/导入/提示词选择空态及有内容，1920/760窗口10项。
- asset-picker：公共资产选择弹窗宽窄2项；detail/tasks为最后移除复选框宽度覆盖、统一任务关闭按钮后的复查，不重复计数。
- parameter-cancel：四个原模式 × 1280/1920/760，共12项模型输入、参数取消重开与底栏可达检查。
- prompt-save：原五模式提示词取消、应用、真实临时API保存、收录与固定版本，两种宽度均通过。

检查包含公共字号、搜索同排对齐、选择态、取消保留与横向边界。代表截图随此目录保存；完整产物在<本地维护路径>。截图使用原站插画与临时素材，不读取生产作品。

首轮发现窄屏旧23px覆盖并修正。换人夹具最初未设置源视频已准备，两个步骤被原业务禁用；补临时状态后到达真实步骤，未解除生产校验。最初工作区夹具dispose先于截图关闭了参数弹窗，已改为保留至截图并断言弹窗实际打开；最终参数回执与截图来自纠正后的夹具。

这些定向检查不代表所有作品内容、任意缩放和长时使用均已验证。未调用任何真实LLM/ComfyUI/生成服务，未重载生产、安装、提交或发布。最终规范与现状见docs/frontend/visual-design-standard.md及维护基线。

最终共有72个不同页面/宽度布局场景通过；参数和任务/详情的同场景复查另存，不累计为新场景。18项相关Node检查通过（视觉归属/准入/任务行为）。[截图浏览](gallery.html)可查看本轮代表页面。
