# 后台同步导致展开项自动收起

用户点击“补充视觉参考”后约两秒收起。临时真实Flask/API、原ES模块和真实watchProject计时复现：剧本和电影都失败，见before.json。

原因分两层：新模式receive对完全相同快照也执行innerHTML重建；真实内容变化时，重绘没有保存原生details开关。只增加快照去重后，空闲轮询问题消失，但真实更新仍收起（dedupe-only.json），确认两个原因同时存在。不是浏览器整页导航，也不是点击事件重复绑定。

修复：相同已接收快照不重绘；两模式共用ui/workspace-view-state.js，在重绘前后按项目/步骤/选择保存展开和收起、滚动、summary焦点及相同媒体元素。素材、文本候选与导出项提供稳定data-view-key；同名“管理素材”排序不串状态。切换作用对象独立记录，dispose释放记录。草稿、输入焦点、弹窗及正在播放时仍保留原延后接收保护；不把视图状态写进项目数据库，不停用任务同步。

after.json两模式通过：真实轮询两次后保持展开且DOM身份不变；显式变化仍能显示新内容并保持展开；主动收起不会被默认open重新打开；步骤之间隔离、返回恢复；聚焦输入不丢。共用层另检查重排同名素材、滚动位置、播放器DOM复用。20项既有异步/素材元数据/准入用例通过，体验登记结构通过。

既有三个视频的ProjectSession已有signature判断，图片及视频接续也有changed判断，本轮没有重写这些接收器；共用素材卡只新增稳定视图身份，不改业务和样式。没有真实模型/媒体生成、生产重载或发布。保存编辑后刷新前端即可加载修复。
