# 代码与配套工作流分开分发

GitHub发布时间森林源码、界面资源、许可、示例配置和维护文档。工作流JSON、模型选用名称TXT及其压缩包通过仓库外的配套包提供，不放入GitHub代码、提交历史或Release附件。模型权重、真实配置、用户素材和运行数据不分发。

## 安装配套包

**配套工具包下载：[夸克网盘](https://pan.quark.cn/s/bfc35a323389?pwd=xUnt)　提取码：`xUnt`**

包内包含工作流、模型选用名称TXT与安装说明；解压后将 `install/` 内的内容复制到网站根目录，保留子目录结构。

1. 从上方夸克网盘下载配套工具包（提取码 `xUnt`）并解压。
2. 将包内`install/`目录的内容复制到时间森林仓库根目录，保留子目录结构。不要把整个`install`文件夹放到根目录下。
3. 对照包内`模型选用名称.txt`，在ComfyUI相应模型目录准备文件，并安装所用工作流需要的节点。清单区分默认启用、旁路/可选以及源图中的模型，不要求全部安装。
4. 按README配置网站、启动服务。安装配套包本身不会启动引擎、下载模型或提交生成。

需要补齐的原始快照：

| 网站相对路径 | 用途 |
|---|---|
| `h3ui/studio_sources/dance.json` | 原8＋4及旧实验兼容来源 |
| `h3ui/studio_sources/official_r2v.json` | 官方Ref2VA来源 |
| `h3ui/studio_sources/official_t2v.json` | 官方T2VA来源 |
| `h3ui/studio_sources/wenxi.json` | 文戏来源 |
| `h3ui/studio_sources/impact.json` | 来源归档，当前选择器未将其注册为独立配方 |
| `h3ui/image_studio/sources/krea-edit.json` | 图片四编辑分支及文生图派生适配的来源 |

原快照保留创作者注释和原始哈希，部分含原作者示例参数或素材文件名，需按自己的素材替换；不含素材本身。文生图及四种图片编辑另提供离线编译的API示例，仅用于理解实际绑定，不能把API图当成原生可视化布局文件。视频的长项目任务、上下文、尾部保存与审核依赖由网站编译器管理，单独导入来源图不能复现整个网站调度过程。

## 首次公开发布的边界

现有本地Git历史已经包含工作流快照和本机维护资料。因此首次公开版本从当前工作树筛选导出，在独立发布目录建立公开历史；原维护仓库的历史、远程、工作树和运行数据保留。许可证和上游来源在公开副本中保留，不将快照导出描述成从零原创。

发布副本排除工作流快照、本地上下文回执与历史交接，生成适合公开仓库的交接及新回执；维护说明中的个人路径改为通用路径。离线节点目录只保留节点定义和枚举结构，清除扫描到的素材/模型文件名，实际文件仍通过本地刷新发现，编译器默认参数保持原样。

发布目录里的`.gitignore`及检查工具保护工作流JSON与配套压缩包，补齐工作流后也不应提交这些文件。原维护仓库中已有跟踪文件不因忽略规则而自动解除跟踪；禁止把它的旧历史直接推入公开仓库。

## 发布检查

检查发布候选文件、暂存区和公开提交可达文件，排除凭据、运行目录、模型权重、用户作品和六个工作流快照。对独立配套包检查文件清单、JSON、哈希与TXT用途；在临时目录将公开代码和配套文件合并，完成必要的离线导入/编译和隔离检查，不启动网站或生成引擎。

文生图真实效果、速度/显存和长片一致性继续按[当前交接](maintenance-baseline.md)标明验证范围。发布不替代生成验收。后续更新仍需同步文档和AGENTS，并显式选择用户自己的发布仓库，不能推向旧镜像origin。
