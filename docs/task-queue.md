# 全局当前任务队列

网站顶部“任务列表”在首页、创作工作区、项目档案和资产库共用。按用户要求仅显示当前执行、排队与尚占用通道的待确认提交；完成、失败、取消后移出。历史仍保留在原项目与资产库，无“全部历史任务”筛选。没有任务时显示空队列。

图片显示编辑任务、项目名、状态、原种子和通道阻挡项目；视频按正在制作的项目汇总；本地资产处理显示进度。展开队列不切换页面或保存参数。打开项目沿用原路由的未保存草稿保护。全局队列使用独立 dialog，不复用或取消制作参数临时副本。

| 操作 | 实际行为 |
|---|---|
| 取消排队 | 仅条件更新尚未开始的图片 / 本地任务；已进入执行则拒绝并要求刷新，保留素材与记录。 |
| 停止后续执行 | 视频当前内部生成完成后保留结果，检查停止标记后不再提交下一个内部任务或片段。原继续操作仍可接续。 |
| 停止当前生成 | 先核对准确 prompt_id 和 `time-forest-<attempt id>` 归属，再调用 ComfyUI `/api/jobs/<id>/cancel`。视频同时设置停止后续标记。引擎确认后由原 worker 释放通道；完成结果优先保留。 |
| 结束等待并保留记录 | 仅图片 unknown、原编号存在且该项目无执行 lease 时可用。用户确认后重查队列和准确历史；仍无记录才终止等待，保留快照、种子、编号及 `closed_without_result`。其他排队任务随后可继续，不重发原提交。找到证据则回项目核对收回结果。 |
| 打开项目 / 资产任务 | 查看正文、结果、详细记录或既有恢复操作；不会因浏览自动提交或停止。 |

停止接口只调用引擎按 ID 原子取消，不回退到全局 `/interrupt` 或清空队列。本机现有 ComfyUI server.py 已确认具备这个端点；未对真实任务测试中断。其他引擎缺接口、离线、归属不明或状态已变化时展示真实错误。HTTP 成功发出请求不等于任务已停止；列表保留“停止已请求”，等引擎结果/队列确认后释放。无 prompt_id 的提交仍需等待编号或原项目核对。

本地文件处理已开始后完成当前操作，队列不伪装成已经杀掉 FFmpeg 或撤销资产写入；原资产库重试/历史入口保留。视频旧未确认提交通过原项目恢复入口处理。当前列表管理网站登记的任务，不罗列或停止直接从 ComfyUI 客户端提交的外部任务。

后端 `h3ui/task_center.py` 从原 ImageStore、StudioStore、LocalTasks、JobManager 汇总。`GET /api/v5/tasks` 返回版本 1，只读记录，不访问引擎或唤醒 worker。`POST /api/v5/tasks/action` 要求明确确认并在实际状态上重新验证，操作不自动重试。没有新增表或迁移；停止标记写入既有 JSON 及当前 lease。图片 dispatch 在取得 lease 后重新读取状态，防止与结束等待竞态导致旧记录复活。

前端 `static/studio/features/task-center/index.js` 由 bootstrap 仅装配一次。每 5 秒更新，后台标签页暂停；确认/执行中暂停轮询替换，保留键盘焦点和被操作任务的准确身份。API 缺失明确提示网站后台需要重启；静态入口版本不代表旧 Python 进程已加载新接口。

隔离检查入口：`tests/test_task_center.py`、`tests/studio_task_center.test.mjs`；真实 HTTP/UI fixture 为 `tests/task_center_ui_fixture.py --port 5098`，工厂使用临时配置与数据库、假引擎，禁生成与启动恢复。不得指向生产配置来验收停止功能。实际检查结果、浏览器与真实生成限制统一见 [维护基线](maintenance-baseline.md)。

## 视频拼接任务

kind=assembly汇总导入视频、AI尾部续接和本地拼接，只显示活动与待确认记录。本地任务停止控制持有的取消标记/子进程，生成停止校验prompt_id与client_id。recover查询原提交，不重发已登记任务，可能继续剩余内部任务；close重查后结束无法确认的等待，记录保留。后台启动不自动重新提交续接。相关实现h3ui/video_assembly/service.py，与旧队列共用通道保护；详见[视频拼接](video-assembly.md)。

## 异步反馈保护（6.3.25）

task-center在确认/发送操作时令更早的列表请求失效；重复确认只提交一次，发送中禁止关闭，成功后再读取实际列表。stop_requested仅显示“停止已请求”，不提前转成取消；完成任务从活动列表退出。销毁时中断列表读取和UI回调，不调用任务停止。公共事实名称来自core/task-state.js；隔离浏览器的队列响应受控，未以生产任务验证停止。见第四批体验交付。


## V3.0 剧本与电影接入

新 LLM job 使用原 cloud lane（authoring_cloud_workers 默认2），电影生成/导出使用原GPU/媒体lane；全局列表仍仅活动任务。新模式取消核对归属；云端停止接收不保证远端停止。重启只标记中断/状态不明，不恢复旧任务。电影状态不明可显式查询确切原 prompt，禁止改号/重发；关闭等待不证明引擎完成。
