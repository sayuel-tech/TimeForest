# 项目档案删除与恢复

## 用户操作

项目档案中，每张卡片提供删除项目按钮。确认后，项目从普通列表及首页最近制作中隐藏；切换档案范围为“已删除”，可恢复项目。旧版记录支持同样操作。也可从资产库→[回收站](recycle-bin.md)→“项目移除的”查看并恢复；统一入口读同一标记，不复制项目或重新创建ID。恢复项目不会自动恢复其中另行移除的生成记录。

这是可恢复删除，不释放磁盘空间。项目素材、生成结果、已入库资产均保留。运行、准备或合成中的项目禁止删除。

## 实现边界

- 新版项目以 JSON 中 deleted_at 标记删除，不搬移目录、不删除 SQLite 记录。默认读取拒绝已删除项目，列表显式指定 trash=1 才显示。
- POST /api/v5/projects/<id>/trash 接收当前 revision；restore=true 为恢复。删除与恢复均增加版本号，过期草稿不能将项目重新覆盖回来。
- 操作占用项目任务锁，避免与生成、合成、素材处理并发。
- 旧版 Registry 持久化相同标记，通过 /api/v5/legacy/<id>/trash 操作。已删除记录不得迁移，需先恢复。
- 旧版原有物理删除接口没有接入新版档案 UI；本次按钮始终调用可恢复接口。
- 首页继续使用默认项目列表，无需单独同步缓存。浏览器已打开的旧页面需重新读取；旧版本写入由后端拒绝。

## 历史检查记录（6.2.3）

6 项非生成回归通过：隐藏/恢复与文件保留、版本冲突、运行任务阻止删除、过期保存不能复活项目、旧版持久化/恢复/迁移保护、旧版运行保护。浏览器使用隔离测试项目验证取消、删除、已删除筛选与恢复，未运行 H3 或 ComfyUI 生成。
