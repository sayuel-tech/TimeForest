# 图片资产创作维护契约

唯一应用内的第四模式image_assets，kind=image；子工具single/dual/region/outpaint/text（文生图）。图片项目、任务、运行、输入、输出分别存储在同一studio.sqlite3的image_表，旧视频表不变。

统一/projects负责目录分派；图片动作位于/api/v5/image-projects，工作区沿用#/p/id。生成编译器接受这五种工具；原四编辑分支保持不变，text由原单图链派生原生文字分支，源附件在模块sources中原样保留。原图、逻辑mask和执行副本分离，所有结果以run/output ID寻址。

草稿有revision，运行固化任务快照；GPU共用JobManager的gpu lane。断线提交不自动重发，仅核对原运行。取消不调用不可靠的全局interrupt。

用户已认可图片计时呈现，现将其作为四模式统一标准，布局与时间块提取到 `ui/run-timing.js`，图片和视频的生成、准备、合成共同调用。保留 `run-clock`、`elapsed` 和公共时钟更新，每秒仅更新文字；切任务/页面读取同一持久记录，退出工作区清理定时器，不重建画布或改草稿。等待显示“已等待”；引擎通道空闲、开始准备输入/工作流时保存 `started`，执行显示“本次任务用时”及已花的排队时间。成功、失败、取消统一保存 `finished`，已结束计时固定。恢复和后续说明更新不重置原开始/结束时间。旧记录优先使用已有 progress 时间，没有执行开始则注明“含等待”；缺少可用时间显示未记录，unknown 或明确结束未确认提交仍显示用时待确认，不补造生成时长。

候选人工入现有资产库，可新资产或新增版本；第二步快捷入库复用原 outputs/:id/library，传 select_output=false，只收藏；省略该字段仍保持第三步原选用语义。catalog 的 quick_ingest_preserves_selection=true 标识后台已加载此行为；缺失时快捷按钮禁用并提示重启导演台，避免旧后台静默改变选用。固定引用，视频联动复用库use-plan/use-apply。Krea普通指令与H3模板分离。

按用户要求不运行ComfyUI测试；编译/几何、数据调度、资产联动及最终UI做少量关键检查。生产发布前备份，测试使用独立数据根且禁止生成。

候选整理见[候选记录整理](candidate-records.md)：在“生成与挑选”移除未选用结果，候选编号稳定；失败/取消且无输出记录也可整理，全部移除后仍显示恢复入口。当前选用先换选，运行或待确认时拒绝整理。原图、快照、库资产和后续任务输入保留；恢复不自动选定。

## 使用

首页选择“图片资产创作”，创建时可选择单图、双图、局部、扩图或文生图。四个编辑工具在右侧上传/从资产库选择图片；双图A是底图、B是参考，整体人物和只换脸有不同指令示例。

文生图在同一工作区选择第五个工具，第一步为“描述与创作”，填写画面描述即可，不要求A/B或遮罩。右侧保留输入/项目，制作参数按文生图提供底模、编码器、VAE、输出像素面积/比例、采样与种子；不显示编辑LoRA、参考权重或图像理解字段。文生图与编辑工具之间切换会创建独立任务并保留原任务，切回任务可继续原草稿。第二步可反复重新生成、挑选/移除候选、下载和快捷入库；无底图所以不显示对比原图。第三步仍可将所选结果作为单图编辑新底图，或引用到视频。技术来源与绑定见[参数映射](frontend/parameter-map.md#文生图派生适配)。

右上方是唯一“制作参数”入口，直接复用视频相同的按钮、工作流说明排列及分类对话框，作用对象是当前图片任务。打开时复制当前任务参数，取消／关闭／Esc 放弃本次弹窗编辑；“应用到任务草稿”只写回当前任务，再点击“保存草稿”持久保存。外层未保存指令和画布笔画保留。“恢复默认”读取当前工具公开字段对应的后台 defaults/models（模型含网站 image_models 配置），包含种子及适用的扩边等高级参数，只改弹窗临时副本。取消可撤销；应用后再由保存草稿持久化。不改原图、指令、遮罩、其他工具未公开字段或历史候选；缺少任一默认值时整体拒绝，不补造前端默认值。编辑侧栏为素材／输入／项目；项目名称在“项目”页签修改并随草稿保存。采样、种子、模型、像素面积和双图/文生图输出比例只在制作参数中调整，不另设侧栏设置页签或重复入口。

字段按当前工具适配，不照搬视频时长、声音或插件全量字段。像素面积与图像理解尺寸分别标明 MP／px 及作用阶段；图片 A 参考权重只在双图工具公开，其他工具保留该历史字段但编译不消费。种子模式为每次随机／固定种子，固定 0 有效；非法、小数及超出安全整数范围的输入保留并提示，不静默转成随机。详细持久字段和执行落点见[参数映射](frontend/parameter-map.md)。

局部模式用画笔标注、擦除、撤销或清空，保存时独立存mask。源图透明度保留于原件，执行RGB副本以白底准备；涂蓝是语义引导，区域外可能变化。扩图在画布工具“扩边设置”选择目标比例／锚点或输入四边值，也可继续拖边；这些控件与参数描述使用同一任务字段。页面显示工作图、画布、最终输出的真实尺寸。

生成前先保存。第二步“生成与挑选”可对比、下载和反复“重新生成”：按当前任务的原图、指令、制作参数及原种子规则提交新候选，不把上次结果变成底图，不新建编辑任务、不覆盖旧候选。底部“返回上一步”回到原编辑任务。下载图片旁的“加入资产库”直接收藏当前查看候选，停留第二步且不改变已选用结果；成功后显示“已入库 · 查看资产”。第三步仍保留将结果作为新任务底图的“继续编辑”。保存与使用页支持新建资产/现有资产新版本，新图片成为该版本主媒体，旧媒体和旧版本保留。“用于视频”先入库，再选择视频项目及片段，沿原引用影响预览确认后应用。

## 编辑任务废弃与恢复

图片编辑任务列表支持“− 废弃当前任务”，确认后保存草稿并将该任务及候选退出工作列表，取消该任务的结果选用，自动切到剩余任务。最后一个任务也可废弃，显示0任务空态，可新增或恢复。运行/排队/待确认或项目操作占用时拒绝废弃；已入库资产、视频引用、原素材和运行快照保留。废弃任务在资产库回收站“项目移除的”以编辑任务分类信息呈现，可恢复；恢复不自动选用、生成，也不恢复其中另行移除的候选。

任务在原 image_tasks JSON 上记录 discarded_at，不删记录、文件或数据库表。`POST /api/v5/image-projects/<pid>/tasks/<tid>/discard` 接收项目 revision 和可选布尔 restore；使用原项目操作lease及图片存储锁/事务。工作区snapshot及档案摘要只展示未废弃任务及所属运行/输出；旧保存计划经revision拒绝，草稿接口不能隐式删除任务或重新写入已废弃ID。已废弃任务不能预检/新生成，候选不能选用、继续编辑、入库或独立恢复，先恢复编辑任务。父项目已移除时先恢复父项目。catalog.task_discard_version=1 标记后台已加载；旧进程缺标记时按钮禁用并提示重启网站。

## 运行与恢复

开关image_assets_enabled控制模块组装，原三模式保持兼容。模型默认键在image_models配置中，任务保留自己的models。普通“刷新本地模型列表”通过现有LocalModels扫描对应目录，不需要ComfyUI在线，也不加载权重；使用目录提供的完整相对文件名，目录未发现的当前选择仍保留并提示。节点声明单独由“同步节点能力”在线读取；本地日常换文件无需先同步节点。远程引擎仅使用匹配该引擎地址的节点缓存，具体来源、失败保留及额外目录规则见[本地模型目录](local-model-catalog.md)。插件来源版本86f886dac23013d88996e3a2e99093ba44d322fb保持不变，本次未安装升级环境或启动生成引擎。

底模、图文编码器（CLIP）及图片 VAE 与视频同类字段一致，使用模型列表选择；LoRA 使用可输入的文件列表，保留完整相对名字。图片入口和目录刷新会检查实际网站 API 的参数契约。网站进程尚未重新加载、仍返回旧目录时，明确提示前后端版本不一致；先保存已有编辑，再重启网站服务并刷新，无需启动 ComfyUI。不会用空分类窗口表示参数已经加载。

运行只按prompt_id与固定SaveImage节点收集输出。未知提交禁止自动重发，使用“核对原提交”；无法唯一匹配时保留记录。等待中的任务可取消，不使用全局interrupt误中断其他任务。重启只恢复已登记运行，不自动生成新图片。

保存、请求与运行错误显示分类摘要，支持展开／复制原始错误。后端保留收到的错误文本及失败历史状态，节点／字段信息随原文展示，不猜唯一原因、不自动换模型或调参。错误和模型刷新均不清空素材、候选、资产固定引用或当前编辑。

数据库image_projects/image_tasks/image_inputs/image_runs/image_outputs及image_changes与旧表并存。目录为data_v5/<pid>/image_inputs、image_runs；执行副本在Comfy输入目录time-forest-images/<run>。项目回收不会删除库原件。

本次必要备份、隔离开发资料和执行账本位于<本地维护归档>。回退优先关闭image_assets_enabled或恢复代码；备份当前数据库后保留image_新表，禁止用旧库覆盖发布后新内容。

历史接入检查包括tests/test_image_studio.py中的关键行为、原保存门、JS语法及普通／窄屏页面查看，不作为阶段 B 复跑计数。阶段 B 的实际代码修复、相关隔离界面／保存／真实参数绑定检查及证据统一见[维护基线](maintenance-baseline.md)。真实推理、画质、模型组合、量化兼容、耗时、显存和最终用户体验不由这些非生成检查证明，仍待用户验证。

## 等待生成通道的排查

“等待通道”不等于ComfyUI未启动。图片Runner遇到任何项目的 submitting/running/unknown 旧记录时，优先核对原提交并阻止新生成；引擎队列为空仍可能被unknown保护阻挡。顶部[当前任务队列](task-queue.md)显示跨项目阻挡记录，可取消排队、请求停止准确的当前生成，或明确确认“结束等待并保留记录”。后者先重查队列与历史，缺失仍不表示从未执行；保留未确认标记，解除占用后其他排队任务可继续。既有“核对原提交”入口保留。不要靠删除记录、全局中断或强制释放执行 lease 处理。实际服务加载与验收状态见维护基线。
