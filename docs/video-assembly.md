# 视频接续：视频拼接与AI尾部续接

本地代码版本6.3.20使用 `video_assembly`，能力契约 `assembly_contract_version=1`。首页第五入口只在后台声明支持时显示；旧后台需重启导演台后刷新。原四模式、生成默认值、原始工作流和用户数据保留；本轮没有提交或更新GitHub。

6.3.16增加独立视频轨道（assembly_track_version=1）：选用结果后追加到左侧目录；原视频与已选续接均可上下移动或拖动，排序自动保存，右下角拼接导出及最终媒体严格按此顺序。重复选用不重复追加，更换同一续写段候选保留轨道位置。旧项目未记录顺序时只读投影原片及已选续接，无需重新生成或数据库迁移。旧后台未加载能力时明确提示重启，不允许前端假装保存顺序。

6.3.15修复读取状态后编辑正文、时长或素材用途不进入当前草稿的问题：无变化轮询保持已绑定对象；有变化时只有能够同步重绘才替换。编辑、聚焦输入、参数弹窗和视频播放期间的迟到响应不替换表单；暂停后后续轮询读取最新状态。生成前仍先保存，失败保留草稿并停止提交。切换步骤时素材事件只绑定实际存在的面板。此次为前端修复，已打开网页需强制刷新；不改变后端契约或实际生成语义。

6.3.14将模式显示名统一为“视频接续”，首页使用独立的胶片延伸森林河流插画；内部video_assembly标识、原API及既有项目名称保留。美术来源见[美术资源](image-assets-art.md#视频接续入口插画)。

6.3.13增加assembly_reference_version=1。第一步右侧“导入”集中资产库与本地视频选择，底栏最右侧是下一步，其左侧为直接拼接导出；该动作进入成片页，不立即执行。第二步添加续接后默认显示素材页，本地图片/声音与资产库参考进入当前续写段。旧后台缺少参考能力时明确提示重启加载，不显示假成功。

参考卡可修改用途/角色、移除本段引用；可明确沿用上一续写段素材。图片/声音按实际Picture/Audio顺序进入当前配方，原片尾部上下文仍独立存在。参考精度在制作参数中按实际reference_size绑定。新增段缺参考字段按空列表读取；素材变化只作用于后续草稿/生成，已选候选与旧运行快照不被重写。库引用固定版本，资料PROMPT不加入正文。没有数据库迁移。

共同制作参数、底部动作、素材呈现的维护位置见[公共界面](frontend/shared-ui.md)。

## 使用流程

1. **视频与排序**：从本地多选视频，或在公共资产选择器中多选视频资产。保存项目副本和资产固定版本；上移/下移或拖动调整顺序，起止点只改变使用范围。项目名称在右侧项目属性修改。
2. **续接与挑选**：视频目录加号在当前步骤打开“添加视频”弹窗，可导入本地视频或从资产库多选；取消不跳转也不保存，添加前先保存现有草稿，成功后追加并选中新视频，继续停留第二步。保存失败停止导入并保留输入。选择原片，添加续写段，填写后续画面与声音以及希望新增时长。顶部制作参数可选跳舞8＋4或官方续接适配；生成、重生成、连播片尾与候选、选用结果。选用后自动成为左侧独立片段，可预览并与原视频一起排序；右侧拼接导出进入成片检查。继续续接会添加下一条续写段，以上一条已选结果为前文。
3. **成片**：按当前顺序拼接原片与已选续写，下载或加入资产库。无需续接时第一步可直接进入成片；仅拼接无需ComfyUI。添加但未选用的续写段需完成或移除，不能静默略过。

原片不会被AI重新生成。AI尾部续接只延续前一段，不自动生成与后一任意视频匹配的过渡；不包含尾帧定格、多轨、字幕、调色与复杂转场。

## 原片段制作参数

6.3.17在来源页原有信息下增加默认收起的“查看原片段制作参数”。从资产库导入时读取所选媒体固定版本的运行记录；模型、画布、采样、LoRA、参考/声音及低显存等按现有制作参数定义和分组显示，种子0和关闭/零强度等值保留。不补默认值、不读取原项目当前设置、不把完整工作流节点当作表单，也不自动应用到续接草稿。无参数记录则不显示此折叠区。

三视频模式读取入库records.manifest.settings及实际种子；长片段内部任务、成片所选各段分别列出，不合成一套虚构参数。接续候选读取冻结snapshot.extension中被选配方和run.seed；仅拼接导出的记录没有单一生成配置时保持空白。读取portable_pack保留的来源封装，但不会任意递归解析插件字段。

新导入固定保存只读source_parameters；此前已导入视频按provenance中准确asset/version/media/hash补读，不批量改库、不改变用于候选来源校验的provenance。选择多媒体资产的alternate时不能误用根资产/封面的参数；无媒体级来源的旧记录仅在单媒体时允许根来源兜底。已读取的参数不因资产后续修改而改变，保存接口不能从客户端改写。当前轨道选中的接续结果显示自身运行记录。

assembly_source_parameters_version=1标记后台能力，旧后台提示重启，不能把尚未加载的功能伪装成没有记录。实现见source_parameters.py / source-parameters.js；查看只读，不加载模型或连接ComfyUI。

## 制作参数与来源

6.3.18修正模型自动补全被当前完整文件名过滤的问题。五模式的底模、编码器、VAE、加速/普通LoRA统一使用 `ui/model-selector.js`：下拉展开完整目录，不以当前文件名过滤；“手动填写文件名”折叠区保留完整相对路径。目录外的当前值继续保留并提示，输入、选择、刷新均不自动替换模型。刷新区域与分类导航的间距在公共外壳维护；本次仅前端更新，保存当前草稿后Ctrl+F5即可加载，不要求重启ComfyUI。

顶部唯一入口共用 `ui/production-settings.js` 的外壳、分类与控件。当前续写段与整个项目的导出规格明确分组；取消保留外层草稿，应用只写草稿，保存经revision校验。恢复默认重置当前配方、种子与续接声音临时值，不改正文、视频、候选或另一配方草稿。两配方草稿切换可往返保留。导出尺寸初始取首视频显示尺寸（偶数对齐），之后排序不会改变。

工作流由 `video_assembly/compiler.py` 投影到既有 `Recipes.compile`，再以独立适配标记 `assembly.dance_split` / `assembly.official_image`、revision1处理外部尾部。原 `dance.json` / `official_r2v.json` 字节不变；模型加载和对应采样主体保留。官方选项是“官方来源＋网站续接适配”，不能称为官方原生拼接模板。没有新改默认配方或全量搬出插件字段。

字段与实际节点只维护在[参数映射](frontend/parameter-map.md#视频拼接模式映射)。本地模型刷新不启动ComfyUI；实际生成动作连接用户已运行的引擎、检查当前节点、提交图，不调用引擎启动器，不下载模型、不自动试参。

## 时长与声音

6.3.20修正AI片尾预处理补黑边：新续接保留源视频的显示尺寸（规范旋转/SAR和帧率），不预先按一采画布缩放补边，由既有MotionContext节点按自身规则适配完整画面。原1248×704视频进入832×480一采时，旧处理会加约5/6像素上下黑边，生成把它延续到结果；此类画布取整比例差不应通过预处理补黑解决。普通拼接导出的contain/cover保持原样；源片已有黑边不会被自动裁除，明显不同画布比例的构图仍由用户参数及节点处理。

新运行快照固定tail_preparation=source_geometry_v2；旧运行缺字段时恢复仍按legacy_contain_v1准备，不把旧提交的上下文换成新规则。没有改默认画布/模型/采样、原工作流节点或已完成文件。目录、项目快照和health报告assembly_tail_preparation_version=2供核对后台加载。此项是后端修改，需重启导演台后再生成验证；旧候选本身的黑边不会因刷新自动消失。

原片先按真实时间戳、显示方向和像素比例处理。混合尺寸默认等比例补边，也可明确选择填满裁切；输出帧率24/25/30/50/60，转换保持时长而不是更改播放速度。原文件保留，处理副本会重新编码，不能称为无损拼接。

外部上下文取裁切后末尾：当前适配为22帧视频及1秒对齐声音，生成链24fps。准备缓存使用FFV1与PCM，避免上下文缓存额外有损编码；不能恢复压缩原片已丢失的信息。少于1秒的有效原片可以普通拼接，AI续接明确提示长度不足。

无音轨原视频正常拼接，对应时间为静音；AI使用标注为无声来源的静音上下文。续接可选生成声音或静音，原片声音保持。请求生成声音却没有音轨的结果报错，不补造成功。模型内部输出包含前文；裁除22帧及对应声音后只追加新增部分，长续写按当前合法帧数拆内部任务。希望时长按24fps量化，预检给出实际新增秒数。

## 视频轨道与导出顺序

`h3ui/video_assembly/track.py`与前端`modes/video-assembly/track.js`按原视频和已选成功续接投影轨道。`assembly.track_order`保存`clip:<id>`或`extension:<id>`顺序，续接槽解析当前选用候选，不复制媒体、不新建重复源视频。保存只接收当前项目完整且唯一的轨道键，拒绝遗漏、重复或外来ID；导出先校验原生成来源，再按顺序冻结parts和媒体哈希。

新选用槽追加末尾，替换候选保留槽位。改变源视频范围或上游选用仍按原依赖规则清除下游选用，失效槽退出轨道，候选与文件保留。轨道移除续接复用续写段可恢复移除；移除源视频也隐藏其关联续接，恢复不自动选用。尚未选用的续写段仍需选用或移除后才能导出，不能因为不在轨道就被静默忽略。

## 保存、整理与任务

项目主体继续使用现有SQLite JSON和revision，无数据库迁移。运行中可保存后续描述和参数草稿；独立draft_revision区分作者修改与后台进度，运行快照不变。原视频、使用范围、资产版本/哈希、续写配置、正文、实际种子、前置候选和导出序列分别冻结在运行快照。修改参数或正文不会重新解释已选候选；需要重新生成并选用才改变成片。改变原片使用范围或上游选用会清除依赖续写的选用，旧候选仍保留；每个原视频及已选续接可以独立排序，排序不重新生成，也不改变当时的尾部来源。轨道顺序与生成依赖分开维护；不将视觉上移动到旁边的片段冒充原生成来源。

导入、生成、拼接接入同一个全局活动列表；完成/失败/取消后退出列表。原片段/续写段移除进入回收站项目类，续接候选/成片移除进入生成类，资产仍在资产类。恢复先满足父级存在，不自动选用、启动或恢复另行移除子项；最后一个视频也能移除并重新导入。当前选用、运行和待确认记录受保护；移除不删除媒体或已入库资产。

媒体处理停止只控制本次持有的子进程与取消标记。生成停止核对prompt和client归属，不全局中断。提交不明时保留快照与任务编号，可查询恢复或明确结束等待；不会自动重试同一提交。恢复可能继续尚未提交的后续内部任务，界面会说明。已取消任务不自动恢复执行。

快捷入库与库内项目结果导入使用同一来源去重键，收藏不等于选用。导入API接收文件或资产/版本/媒体ID，不接受客户端任意文件路径；已有项目不能借用旧视频写接口绕过序列服务。
