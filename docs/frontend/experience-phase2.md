# 共同体验第二批：页头、步骤和操作区

本地静态版本 6.3.23，2026-09-08。承接[体验方案](../product/experience-consistency-plan.md)和[首批交付](experience-phase1.md)。本批改善五个模式的共同导航和操作位置；候选、播放器和完整异步整合仍属后续批次。

## 实际修改与公共归属

- `ui/workspace-chrome.js` 是五模式唯一项目页头/步骤模板。统一项目档案、模式与状态、名称与摘要、右侧制作参数；模式只提供名称、步骤、状态和参数入口 ID。图片保留标题/状态的实时更新 ID，无任务时保留新增与回收入口。
- 原三视频的 `app/workspace-controller.js`、图片 `features/image-results/workspace-view.js` 和视频接续 `modes/video-assembly/workspace.js` 接入相同模板。步骤仍调用原模式保存/准备门，模板不提交生成；方向键/Home/End移动焦点，Enter/Space保留原生按钮行为。
- 底栏继续复用 `workspace-actions.js`。换人第一步也接入；保存草稿与返回放左侧，检查、下一步或主操作放右侧。换人第二步补回原有返回入口；图片结果页和保存页的返回同样放左侧，不再因暂无候选而把返回变成主动作。
- 删除图片窄屏底栏的四处专属样式覆盖，公共 `workbench.css` 负责间距、换行、对齐、长名称省略和步骤横向容纳。窄屏底栏进入正常文档流，可滚动到达，避免遮住编辑区。项目页头不继承全站导航的吸顶规则。
- 换人源视频/角色图、图片 A/B 导入选项复用 `reference-assets.js` 的 `importOptions`。本地和资产库维持同级，各自保留原图角色与导入目标；视频接续已有的导入页、就近弹窗和逐段参考素材继续保留。

不合并五模式的画布、分镜、审核、轨道和单条结果业务操作；不更改字段、保存载荷、配方、默认参数或后端接口。文生图没有原图导入，文生视频没有必需的参考素材，不补造相同按钮来凑齐页面。

```powershell
node tools/check_experience_contract.mjs

```

30 项 Node 检查通过，其中包含新增模式漏登记 chrome 的拒绝测试。体验结构检查通过，仍保留五模式历史缺口，不视为整套体验完成。

使用现有 Chrome 与 websocket-client，通过 CDP 截取实际视口，避开命令行截图滚动后的空白。真实 Chrome 五模式各 1280×1000 / 760×1000 窗口，共 10 例通过（页面可用宽度因滚动条分别为 1262/742）：

| 场景 | 实际结果与范围 |
|---|---|
| 导航 | 每页唯一公共页头与制作参数入口；方向键只移动焦点；跨步骤回来保留实际可编辑提示词 |
| 保存 | 换人自定义正文、参考图/文生提示词、图片指令、接续描述经过各自原保存路径后，读取隔离 API 内容一致 |
| 参数 | 打开、取消后留在当前步骤；本批未改参数本体，不重复运行模型组合 |
| 导入 | 接续第二步加号打开就近弹窗，取消仍在第二步；没有执行真实导入/资产库事务，原导入绑定和目标保持 |
| 视觉 | 保存位于左支持区、主操作位于右动作区；宽屏组不重叠、长标题省略、页面无横向溢出；窄屏底栏非吸顶且可滚动到达；已查看宽窄截图 |
| 生成边界 | 三视频受控 API 的生成/准备请求计数为 0；图片与接续用真实临时 API，接续只有合成视频导入记录；没有 ComfyUI、模型调用或成片生成 |

前三视频使用受控保存 API；图片使用真实图片服务/临时数据库；接续使用真实应用/临时数据库和 FFmpeg 合成的两秒视频，生成功能禁止。结果不能代替真实生产数据或生成效果验证。

## 后续约束与交接

`experience-contract.json` 和结构检查新增必填公共入口 `chrome`；新模式必须声明页头/步骤适配或给出业务不适用依据。普通新页面与已有模式新增功能仍按[体验准入](experience-admission.md)核对全部受影响调用方，不得另写私有页头、步骤或底栏响应式副本。结构检查不是视觉检查，未接入自动 CI。

下一批处理候选状态、播放、重新生成/选用/入库反馈与恢复入口；最后再处理完整异步一致性。用户仍需在日常工作中体验本批位置与密度是否协调。当前只交付本地代码与文档，未重启生产网站、提交、推送或发布；公开 GitHub 仍为 v6.3.20。
