# 统一参数与交互契约

本契约合并 V4 方案中的参数维护规则，适用于现有三个视频模式和图片资产创作。阶段 B 已将图片接入现有制作参数公共外壳，按工具适配字段、草稿和错误行为；尚未实现的后续工作流能力见第 9 节。已认可的工作区、公共视觉、生成核心、默认值和用户数据继续保留；详细字段与节点绑定只维护在 [parameter-map.md](parameter-map.md)。

## 1. 功能稳定，参数随工作流适配

功能模块按用户任务定位。相同用途的新工作流进入原功能的工作流选择器，不新增一级模块或整体重做好用的工作区；只有新的用户任务才走[添加创作模式](adding-a-mode.md)。模型家族用于内部实现复用，不决定产品导航。

显示字段由当前功能、工具、所选工作流及条件决定。统一名称语义、单位、分组、控件、作用域和动作行为，不要求所有工作流显示相同参数。同用途工作流的接入路径见[工作流适配契约](../governance/workflow-evolution-contract.md)。

## 2. 用户控制与网站责任

用户选择模型、LoRA 与参数组合，ComfyUI／插件进行实际校验与执行，用户判断生成质量。网站负责正确呈现、保存、必要转换、绑定、请求安全和错误反馈；不能把错绑定、漏字段或静默重置归咎于用户。

保留格式可解析、种子精度、路径／素材权限、数据保护及网站确实无法表达的结构检查。节点声明、网站表达限制和推荐值须分别说明，不以质量推测、显存猜测或维护者名单封锁普通模型与参数。当前代码已有的范围／结构限制仍按事实登记；本轮不修改或扩大原有能力，后续变更先核对限制来源。

推荐值用于初始化或用户主动恢复。滑条的常用区间不能冒充无来源的硬限制；有更宽输入需求时复用公共数值控件规则。派生值只读说明或明确联动，不能呈现可编辑字段而在编译时仍取常量。

## 3. 精选公开项与业务工具

常用字段放在主要参数区域；低频有用字段放对应分类的展开区域；连接、中间态和当前不需调整的字段留在工作流／适配代码。三层是呈现方式，不是权限等级。新工作流只需说明拟公开字段的用途，不要求审核全部插件字段，也不把其余字段全部堆入“高级”。

参数呈现以前三视频模式已认可的信息密度和开放范围为基线；其他公共体验依据用户对该设计的具体认可，计时标准见第11节。图片画笔、遮罩、拖动扩边属于业务工具，保留在图片工作面；必要的精确数值在相关区域呈现，并与画布共享同一字段状态，不为视觉统一搬入模型参数弹窗。

## 4. 公共语言与分类

沿用现有分类键及顺序：`core / picture / sampling / assets / lora / memory / advanced`，由 `ui/production-settings.js` 统一外壳与控件。当前视频标题为“工作流与模型／画布与输出／两采与时长／参考与声音／LoRA／低显存／高级模型组件”。图片没有两采、时长和声音，适配为“采样／参考图”；没有公开低显存字段，不显示空组。其余同语义组沿用原名，不重排三个视频模式。

| 语义 | 公共表达及边界 |
|---|---|
| 执行方式 | 工作流；官方／优化可作为名称和来源说明 |
| 模型文件 | 底模文件、LoRA 文件、相应用途编码器／VAE；保留完整相对文件名 |
| steps | 采样步数，并按结构说明总步数、一采、二采或独立精修 |
| sampler / scheduler | 采样器／调度器；必要时标一采、二采或两采共享 |
| 几何 | 分辨率、宽度／高度、像素面积、边长倍率；标单位和作用阶段，MP 不等于画质 |
| seed | 种子模式：每次随机／固定种子；实际种子以本次运行记录为准，0 有效 |
| LoRA | 文件、强度、Bypass · 跳过本槽；槽位和旁路能力取决于真实适配 |
| 模型发现 | 刷新本地模型列表；不等于节点同步或兼容性认证 |
| 节点声明 | 同步节点能力；单独说明来源和在线需求，不把全量同步变为日常换权重的前置步骤 |

参考权重、CFG、LoRA 强度不能混并；图像理解尺寸不等于最终输出尺寸；原生生成帧率不等于导出帧率。稳定字段 ID 不使用中文标签作存储键。

## 5. 同名制作参数的目标交互

以视频现有分类对话框为复用基准，让图片接入公共外壳，包括标题、分类导航、临时副本、帮助／错误及底部操作。四工作区的顶部入口直接共用 `productionSettingsAction`，保留视频原按钮及工作流说明排列。图片只有这一个制作参数入口，侧栏为素材／输入／项目；项目名称在项目属性中编辑。只提取需要共享的参数呈现与行为，不合并所有图片／视频业务控制器，不改已认可的视频工作面。

弹窗标明作用对象：视频项目、片段或图片任务。当前视频项目参数、片段种子及图片任务参数各保留原作用域。目标行为为：

- 打开读取当前外层草稿，编辑只写临时副本；分类切换不改数据。
- 取消、关闭、Esc 丢弃本次弹窗编辑，保留打开前外层未保存草稿。
- 应用仅写回明示的草稿；保存不等于生成。保存影响确认仍由现有项目事务处理。
- 模型刷新不覆盖编辑、不丢画布笔画；图片不另设侧栏参数副本。画布工具中的扩边精确输入与弹窗按同一字段定义读取当前任务，不能两份状态相互覆盖。
- 恢复推荐值只作用于用户明确选择的参数范围，不改素材、正文、历史结果和资产。
- 切换工作流只显示当前工作流实际消费的字段，保留旧工作流私有草稿，切回可恢复；分类、按钮及保存语义不变。

图片公共弹窗、取消／应用／保存和刷新保留草稿已实现；图片新增“恢复默认”，范围是当前工具全部公开制作参数及模型（包括种子及适用的扩边字段），默认来源为后台目录的 defaults/models，模型遵循网站配置。恢复只改临时副本，取消可撤销，应用后再保存；缺默认值整体拒绝，不改素材、正文、遮罩、候选或其他任务。工作流私有草稿切回恢复仍属于后续要求，见第 9 节；不能把该要求写成现有用法。

## 6. 种子与模型选择

随机／固定沿用视频已有表达。图片通过显式模式适配原有 `null / 整数` 存储，不迁历史数据。固定 0 保留，前后端检查十进制安全整数；非法值、小数及超过精度的值保留并反馈，不截断或悄悄变随机。运行显示对应的实际种子，不能把当前草稿当作历史运行参数。

普通兼容模型／LoRA 更新应为放入现有加载器目录、刷新、选择，不登记、不发版。四模块普通刷新复用本地文件扫描；图片的在线节点能力同步单独提供。远程引擎只展示对应地址的缓存／在线声明，不扫描本机充当远程清单。当前文件缺失时保留原选择并提示；刷新失败保留编辑与旧成功目录，显示实际来源、时间与错误。按目录提供的完整相对名字选用，目录发现不等于生成兼容性认证；详情见[本地模型目录](../local-model-catalog.md)。

五模式的底模、编码器、VAE、加速/普通LoRA统一使用 `ui/model-selector.js`：下拉展开完整目录，不以当前文件名过滤；“手动填写文件名”折叠区保留完整相对路径。目录外的当前值继续保留并提示，输入、选择、刷新均不自动替换模型。参数目录必须来自当前网站进程的真实 API，`core/image-catalog.js` 在进入工作区和刷新时核对版本及原四工具描述，声明或使用text时另核对文生图能力与字段。缺契约时明确提示网站前后端版本不一致，不能展示空分类冒称已加载；修复要求重启网站服务并刷新，不要求启动 ComfyUI。

## 7. 运行、错误与资产

草稿、待提交、排队、生成、失败、取消、已生成使用一致的基础语义。图片选定候选不等于视频批准继续；已生成不等于已入库。刷新和失败不能清空候选、素材版本及固定引用。

错误按文本显示，展示摘要、原始错误以及实际收到的任务／节点信息；能确定时定位字段，不能确定时不猜唯一原因。分享日志另行脱敏。保留用户选择，由用户调整重试，不自动换模型或试参数。既有可靠断点恢复可以复用，状态不明先核对原提交以免重复排队。

## 8. 开放一个尚未显示的参数

这属于原功能内的小范围扩展，沿一条链完成：用途 → 稳定语义 ID → 名称／单位／阶段 → 作用域 → 原分类与常用／进阶层 → 真实节点输入 → 默认／约束来源 → 草稿／保存 → 编译与实际记录。

先定位真实图，不猜节点 ID；有同义公共定义先复用。新字段进入现有参数描述／控件，后端 normalize 不得丢弃，compile 不得继续读常量。旧记录缺字段时沿用旧适配默认，不回写历史或让结果无故过期。

只做一次与改动相关的非生成检查：非默认值正确到达目标、取消／保存重开正常、旧缺省行为保持及分类恰当。多个字段可合并检查，不测试参数组合和画质。不能在模板尾部另贴独立表单、绕过制作参数另开弹窗或保存同字段的两份状态；若属于新能力，说明受影响适配，不能用假控件代替实现。

## 9. 阶段 B：当前实现与保留边界

以下为当前源码与相关隔离检查确认的接入情况，静态入口仍为 6.3.2。图片使用真实静态组件、真实图片 API 和临时数据库检查；视频对照使用模拟 API，编译检查离线进行，没有运行 ComfyUI。实际旧后台的重载状态、当前证据、待用户体验和生成验证统一见[维护基线](../maintenance-baseline.md)。

|---|---|---|

## 10. 每次开发交付同步维护

字段变化同步唯一[参数映射](parameter-map.md)和必要用法；公共规则或路径变化同步本契约、PROJECT_GUIDE 及必要 AGENTS 正文／路由。交付前按[上下文维护契约](../governance/context-maintenance.md)核对语义，更新维护基线中的变化、检查证据、遗留差异和下一步，再刷新上下文索引并 check。不能只改日期，也不能把文档维护留给下一次会话。

阶段状态要分别写明：视觉接入、参数语义、代码接入、非生成检查、真实生成和用户验收。上下文文件检查不证明行为一致、图绑定或生成质量；未执行的检查保持未执行。未经授权提交时同批代码与文档留在同一工作树，不自动提交或发布。

## 11. 公共设计复用与计时标准

可复用的模块、控件和设计保持共同规范。新增或修改前先查地图与公共实现；采用用户认可的具体交互/视觉基准，将共享呈现放在 ui 层，模式只传业务数据与行为适配。公共体验调整同批检查所有受影响调用方与专业文档，不复制新版本到各模式，不以模式私有 CSS 悄悄分叉。不强求业务字段、工作流或保存作用域相同，也不借复用重构全站。

| 共同体验 | 现行公共入口（相对 static/studio/） | 基准与边界 |
|---|---|---|
| 工作区视觉层级 | styles/workbench.css；ui/workbench.js | 内容区作为主面板；提示/进度为辅助信息，使用共同边框、圆角和紧凑间距，保留已认可的功能分布 |
| 状态行与计时 | ui/run-timing.js；styles/components.css | 用户认可的图片模式：左侧状态，右侧时间；四模式统一字号、单位和排列 |
| 制作参数入口与弹窗 | ui/production-settings.js | 视频已认可的入口与分类外壳；图片按五工具适配实际字段 |
| 工作区布局与属性页签 | ui/workbench.js | 现有工作区共用骨架，保留图片画布与视频审核业务 |
| 原始错误呈现 | ui/error-feedback.js | 摘要与原始信息可查，不伪造原因或自动调参 |
| 候选移除与恢复 | ui/candidate-records.js | 四模式共用确认与可恢复语义，保留文件、选用保护和已有引用 |

计时统一 runStatusRow / runTiming 的呈现及原 elapsed 格式。图片等待显示“已等待”，开始执行后显示“本次任务用时”，有真实排队起点才显示排队时间。三个视频模式使用同一状态行；源视频准备和成片合成也用相同时间块，分别标明“准备用时”和“本次合成用时”。视频原采样步数、节点说明、错误和准备进度保留，不为排版统一伪造排队记录。

时间来源由各业务适配：使用既有持久时间/进度时间，终态固定；未知提交显示待确认，缺可用时间显示未记录。格式化组件不读取项目、发请求或修改记录。每秒只更新时钟文字，原轮询与切页销毁机制保持；不重建图片画布、改变草稿或生成参数。本轮只统一呈现，不追溯修改旧计时数据。

视觉统一还需核对容器层级、留白、底色、边框和控件对齐。共享计时块本身一致不等于整个页面协调；视频进度沿用工作区面板边框和圆角，内部状态去掉重复卡片底色，提示和工具栏紧凑排列。生成/审核/草稿等功能位置与行为保持，按用户反馈调整外观。以实际页面或隔离浏览器渲染检查宽窄窗口；纯函数结果不替代视觉复核，合成素材也不证明真实媒体完整显示。

文生图新增能力标记text_to_image_version=1及parameters.text，旧四工具参数契约仍为1。文字任务仅公开自身图绑定字段，隐藏编辑条件不消费；跨文生图与编辑另建任务，原草稿保留。节点缺口按missing_by_tool展示和执行校验。参数弹窗的前次close事件不得取消重新打开后的副本。

## 视频拼接的参数作用域

视频接续的定时状态读取不能使输入框与保存对象脱节。无变化响应保留已渲染对象，有变化时接收与重绘同步；接收时复核未保存输入、输入焦点、操作及弹窗，播放导致无法重绘时也暂缓替换。生成前保存成功才能提交，失败保留当前草稿。对应隔离回归见tests/video_assembly_draft_ui_fixture.py，不能以快速连续点击通过替代等待轮询后的真实使用节奏。

视频拼接加入上述公共体验：当前续写段的两配方草稿互不覆盖，项目输出尺寸/帧率/补边策略单独分组；恢复默认不改正文和媒体。运行期间允许保存后续参数草稿，使用独立draft_revision区分作者修改与任务进度，已提交运行仍使用冻结快照。非默认参数经真实临时API到编译节点检查，声音静音绑定结果处理。具体字段见唯一参数映射；两条图的生成效果尚未验收。

视频接续的导出顺序属于项目草稿，不属于模型制作参数。assembly.track_order使用源视频/续接槽ID，经真实API验证并保存；选用结果追加槽、重新选用替换槽而非重复增加。上下移动和拖动自动保存，保存失败保留本地顺序并明确错误；导出先完成保存。生成来源链不随排序改变，旧项目只读展开已选续接，具体兼容与移除语义见视频接续说明。
