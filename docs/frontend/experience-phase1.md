# 共同体验首批落地：参数与保存

本地6.3.22，承接[体验一致性方案](../product/experience-consistency-plan.md)。本批完成制作参数、保存反馈和离开保护的共同操作链路；导航布局、候选/播放器及完整异步状态整合仍按后续批次推进。

## 用户操作与作用域

| 操作 | 五模式共同结果 | 业务适配 |
|---|---|---|
| 打开/编辑 | 从当前草稿建立临时副本，不触发保存或生成 | 三视频项目参数；图片当前任务；接续当前续写段及项目导出规格 |
| 恢复默认后取消 | 放弃临时恢复，不改外层参数、素材或结果 | 接续不重置导出规格；图片只恢复当前工具公开字段 |
| 应用 | 合入明示草稿、关闭弹窗，显示尚未保存 | 不调用保存接口 |
| 保存 | 合入当前草稿，经原保存门持久化；成功后关闭 | 保存当前项目全部未保存内容；图片包含需保存的画布标注，三视频保留原影响确认/运行中独立草稿 |
| 保存失败 | 原始错误留在参数弹窗，输入与未保存草稿保留，可以重试 | 取消不会撤销此前已合入草稿的变化；数据冲突、补登记仍走原服务规则 |
| 保存期间 | 禁止重复提交和编辑，X/Esc不伪装取消正在进行的持久化 | 请求完成后可继续操作；目录读取期间仍可取消并忽略迟到结果 |
| 离开未保存项目 | 留在此页 / 放弃修改并离开 / 保存后离开 | 保存失败留在原项目；不取消后台生成，不改变活动任务归属 |

参数弹窗打开时，站内离开先提示完成应用/保存/取消，避免绕过临时副本。浏览器关闭/刷新对已改参数和外层脏草稿使用原生离开提醒，不宣称浏览器一定允许自定义提示文案。保存影响确认使用独立的共同决策弹窗，不能替换底层参数界面。

## 代码归属

- `ui/production-settings.js`：完整外壳、动作顺序、run操作门、忙碌/关闭保护、原始错误、LoRA槽、种子控件和临时改动标记。调用方只提供校验及业务回调；校验在禁用控件前执行，避免浏览器忽略disabled字段校验。
- `ui/choice-dialog.js`：影响确认及离开决策，独立实例、异步操作防重、失败留存、取消/清理及焦点返回，继承现有dialog样式。
- `ui/draft-status.js`：正在处理、有未保存修改、草稿已保存的共同文案。
- 三视频 `features/workflow-settings` → 原 `ProjectSession.save`；图片 `features/image-settings` → 原遮罩保存及 `ImageSession.save`；接续 `settings` → 原 `savePayload`/save。没有合并会话、事务、数据库或生成状态机。
- 原三视频的片段种子改用seedFields，数据仍绑定当前片段；接续上次实际种子从当前续写段的运行记录读取。图片LoRA继续按真实工具描述显示，并非视频槽位的复制。

前者通过网站路由检查前三视频与图片，图片使用真实临时API/SQLite、视频使用受控API；包含Esc、默认取消、应用不持久化、保存失败重试、影响确认取消/确认、离开停留及失败重试保存。后者以真实隔离接续API检查相同行为中的参数/保存部分，附双击、保存中关闭保护、默认取消、模型目录/手填/刷新、两工作流离线模型绑定；离开保存直接调用共同决策组件与实际workspace适配，未用该fixture重走bootstrap接续路由。

本轮每模式分别检查1280与760窗口，共10例通过；截图检查参数标题、目录间距、分类、按钮顺序和可达性，保留原纸色及排版。Node相关38项、Python相关16项通过。精确命令与本轮证据位置见维护基线，不把模拟API算成真实保存/生成验证。

尚未做真实生成、实际生产服务重载或用户日常体验验收。三视频运行中独立草稿仍保留原保存规则，本批没有对正在生成的真实项目试写。此前审查中的三套页头/步骤、部分工作区错误、普通业务弹窗、候选/播放器和上传/轮询差异仍是后续任务。五模式baseline继续保留，不能因为本批通过就登记整套体验完成。
