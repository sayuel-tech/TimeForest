## 字体与控件层级

统一数值维护在 `static/studio/styles/design-tokens.css`，由 `style.css` 在基础组件之前加载。业务样式消费变量，不能另定义同名变量或按模式重写公共字号。

| 角色 | 桌面 | ≤760px | 使用位置 |
|---|---:|---:|---|
| 页面标题 `--title-page` | 32px | 28px | 项目名、资产库、提示词库、档案、详情 |
| 弹窗标题 `--title-dialog` | 24px | 22px | 参数、选择、导入、确认等弹窗 |
| 区域标题 `--title-section` | 20px | 20px | 编辑区、详情区、参数组、管理子页 |
| 卡片/目录标题 `--title-card` | 18px | 18px | 紧凑卡片与工作目录 |
| 正文 `--text-body` | 15px | 15px | 阅读内容与说明 |
| 普通控件 `--text-control` | 14px | 14px | 按钮、搜索、字段；窄屏文本输入保留16px可读性 |
| 辅助信息 `--text-meta` | 13px | 13px | 来源、规格、分页、帮助 |

普通按钮和单行输入框默认44px，水平内边距按钮16px、输入12px；同一搜索行的输入与动作顶边、底边对齐。紧凑分页使用36px，工作区属性/底栏沿用40px密度，提示词与播放器工具条保持原紧凑角色。主次按钮靠颜色、边框与位置区分，不靠任意放大字号。多行输入不强制44px；上传、卡片、步骤与时间轴使用各自公共组件，不能套普通按钮的固定高度。图标、计时数字、首页海报标题是明确例外，不能把其尺寸用于设置和库页面。

## 区域关系

- 内容页左右边距28px，窄屏20px。面板默认内边距20px，弹窗24px/窄屏20px。使用4/8/12/16/20/24/32px间距，不靠连续空标签或额外嵌套卡片撑布局。
- 工作台保留纵向目录—编辑区—属性栏，电影剪辑页保留横向轨道。库页面共用200px导航及父子层级；业务主体用`minmax(0,1fr)`，长文字不得撑宽页面。
- 页面标题高于区域标题，区域标题高于字段标签。空态应放在它所解释的区域中央，配简短原因和下一步，不使用一个孤立的大标题充当详情区。
- 筛选区明确分成搜索行与选项行，分类路径与列表动作同组，分页在列表下方；不将搜索、收藏、分类标题、回收站和分页交给任意自动换行。
- 提示词选择器根据容器实际宽度布局：三栏→导航加列表/详情上下两栏→单栏。不能仅凭浏览器宽度推断弹窗可用宽度。空态、已选中、长正文和取消均需检查。
- 参数弹窗与其他弹窗使用同一标题、内边距和关闭按钮。参数栏采用受限高度，减少空白；窄屏完整占用屏幕，分类横向滚动，字段区与底部操作可到达。
- 背景留白可用于阅读与媒体，不要求填满每块区域。原图/视频保持比例；禁止为美观裁切实际生成结果。缩略图只改变展示尺寸。

## 现有页面与新页面的交付要求

1. 开发前列出页面/步骤/弹窗、使用的公共外壳和必要业务差异。先在原组件增加所需能力，避免新增私有尺寸体系。
2. 普通功能页按本规范检查；新模式还必须在体验契约声明`designScale`复用。缺声明、变量丢失、顺序错误或重复定义不得通过检查。
3. 执行 `node tools/check_ui_design.mjs` 和 `node tools/check_experience_contract.mjs`。结构检查不等于美观验收。
4. 用临时数据查看受影响页面的宽屏与窄屏，至少包含空态/有内容、选中、长文本、展开和弹窗底部操作。核对字号、同排控件高度、区域对齐、文字换行、滚动归属与横向溢出；检查截图，不只检查DOM。
5. 记录已检查页面、发现并修复的覆盖、仍未覆盖的业务状态；同批更新维护基线、项目地图和必要AGENTS。无需为布局变更做真实生成或压力测试。
