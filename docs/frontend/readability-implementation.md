# 全站任务与可阅读性改造交付

2026-09-09，按用户“开始全站改造”实施 R1—R4。沿用现有网站、数据和工作树；本轮没有改后端、工作流默认值或生成语义，也没有生产重载和发布。

## 已实现

| 批次 | 实际改变 | 保留的行为 |
|---|---|---|
| R1 提示词 | 查找为分类＋宽列表；打开条目进入全文主视图，取消常驻空详情栏和36/40vh正文限制。列表摘要16px、全文17px/1.8行距；有返回、本页上一条/下一条。管理与选择共用同一浏览器。 | 返回保留筛选、分页、列表DOM、滚动和焦点；复制、收藏、旧版本、字段核对、应用和原保存门保持。上下条限定本页，跨页回列表翻页。 |
| R2 正文创作 | 七模式正文消费公共阅读角色；共同属性栏可收起，缺少控制的调用方由workbench补齐。换人编写在普通宽度把源片放到正文上方，宽屏才并排。剧本原故事/原段和电影来源Prompt显示摘要，按需展开全文。图片文生图压缩说明区，把主面积留给画面描述。 | 草稿对象、输入监听、五页剧本/两页电影、来源跳转、确认/保存和后台同步保持。图片编辑仍保留真实画布，长指令可展开。 |
| R3 资产与媒体 | 资产详情优先给资料编辑足够宽度，Prompt/设定可展开编辑；选择器展开预览占整行，长名称换行，取消/导入使用共同动作区。视频审核取消过矮工作台的裁切，播放器按有效比例显示，窄屏对照上下排列。 | 原件不裁切、不补边、不写入；预览不选用、展开应用只改资料草稿。电影横向时间轴与下方操作/来源保持；未修改时间刻度、排序与导出。 |
| R4 配置与管理 | 参数区按内容自然高度展开，统一分组/字段/动作间隔；档案卡片压缩封面、强化名称与说明。首页、任务、回收站、分类、存储、导入页逐项核对，保留符合任务的现有区域。 | 模型选择/刷新、保存/取消、任务停止和回收机制保持。首页水彩海报不套阅读弹窗尺寸。 |

## 公共实现归属

- `styles/design-tokens.css`：普通正文、阅读正文、摘要、辅助文字与控件角色；新增 `text-reading`、`text-summary`、`leading-reading`、`reading-width`。不是把所有小字一律放大，日志仍使用日志样式。
- `styles/task-layouts.css`：工作台主/辅空间、正文读写、媒体审核、配置自然高度等任务层组合规则，最后加载；已有基础/模式样式继续负责底层容器与画布业务。新增任务优先选用这里的组合，不能另写同类私有覆盖。
- `ui/workbench.js`：按实际有无目录/属性插槽分配空间，补齐属性开关；操作只改变布局，保留编辑器节点。未设置偏好的较窄桌面调用方初始收起属性，用户仍可展开。
- `ui/prompt-editor.js`：原展开编辑、只读全文、来源文字摘要/展开。只读全文不会成为草稿；展开编辑返回到原字段，再走原保存。
- `features/prompt-library/browser.js` 与 `styles/prompt-library.css`：同一会话的列表/阅读视图与返回状态，业务API保持。
- `pages/asset-library/detail.js`：只适配资料字段的展开编辑和原本机草稿；不建立第二套资产编辑器。
- authoring/movie 仅把原故事/来源文字交给 `readingDisclosure`；图片仅标识没有画布的文生图意图区，其公共呈现由任务样式负责。

## 页面任务卡的落实

| 页面族 | 主信息/高频操作 | 按需辅助信息 | 本轮依据 |
|---|---|---|---|
| 提示词查找与阅读 | 区别候选 → 读到末段 → 选择 | 版本、来源、分类管理 | 四篇有差异的600字以上正文，中英混排，宽窄返回与准确选择 |
| 长正文编写 | 当前文字、展开、应用、保存 | 原故事、参考、设置 | 七模式长正文，约1500字剧本；属性开关不重建输入 |
| 图片文生图 | 描述目标 → 生成候选 | 输出规格 | 空态不再占主画布面积，编辑工具仍有原画布 |
| 看片审核 | 画面、候选、选用/入库 | 原文、运行记录 | 临时合成媒体，播放/暂停/拖动/错误重试、取消和选用语义 |
| 资产详情与选择 | 辨认媒体、读写资料 | 来源、绑定、历史 | 预览占整行但不选用；展开修改不提前写库 |
| 参数/管理 | 字段/状态/对象与操作后果 | 高级选项、日志 | 七模式参数＋首页/档案/任务/存储/分类/回收站/详情宽窄布局 |
