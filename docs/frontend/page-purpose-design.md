# 全站页面任务卡与改造清单

配套[设计规范V2](visual-design-standard-v2.md)。本文件是目标与待办，不是实现完成报告。2026-09-09本轮只复核已有页面结构与相关样式，没有重新调查模型、API和数据库。

## 每页必须回答的任务卡

| 项目 | 内容 |
|---|---|
| 任务 | 用户来这里完成的主要决定 |
| 主信息 | 必须连续阅读、看清或同时比较什么 |
| 高频操作 | 按实际工作顺序列出 |
| 辅助信息 | 哪些需要同时看，哪些按需查看 |
| 布局状态 | 查找、阅读、编辑、未选中、已有结果时怎样分配空间 |
| 公共机制 | 外壳、底栏、素材、Prompt、返回/取消、错误、状态等实际入口 |
| 例外理由 | 例如时间轴可横向，正文不能横向阅读 |
| 检查情境 | 用什么具体内容完成什么动作，观察结果及不足 |

## 库和文字组件

| 页面 | 用户任务与主信息 | 布局方向 |
|---|---|---|
| 提示词选择 | 查找候选、读全文、确认适用性 | 查找列表占主体，全文另一个主视图；返回恢复位置，不常驻空详情栏 |
| 提示词管理 | 阅读、改写、分类、复用 | 复用查找/阅读；管理动作依附当前对象，编辑有足够正文空间 |
| 版本/生成时文字 | 核对当时实际使用内容 | 正文优先，版本/来源简短或折叠，不当小号日志呈现 |
| 资产库 | 辨认、查找、整理素材 | 名称、类型、关键规格和可辨认缩略图同时可见；不只追求每屏数量 |
| 资产选择 | 找到本步骤可用素材 | 浏览为主，需要时放大预览；保留选择和引用核对，不塞满资料表单 |
| 资产详情 | 看媒体或编辑资料 | 媒体查看与长资料编辑可切换重点；不能让完整资料永远挤在半个窄栏 |
| 导入方式/预览 | 选来源并确认导入对象 | 简短来源选项；下一状态以文件预览与处理反馈为主 |
| 分类/回收站 | 整理或恢复对象 | 对象、分类、来源和后果清楚，缩略图辅助辨认 |
| 本地存储 | 查占用、备份或恢复 | 存储事实及日常备份优先，迁移/高级选项按需展开 |

## 七模式逐步骤的空间优先级

| 模式与步骤 | 主任务 | 布局重点 |
|---|---|---|
| 换人1：源视频与角色 | 确认源片和目标角色 | 主预览与角色都可辨认；说明简短，导入就近 |
| 换人2：分段与替换 | 定位片段、写替换要求 | 当前片段与正文有足够空间，技术细节不挤窄文本 |
| 换人3：对照审核 | 判断替换结果 | 原片/结果有效画面同步对照；必要时收起素材栏 |
| 换人4：成片 | 检查并使用作品 | 播放器、成片规格、下载/入库；运行历史按需查看 |
| 参考图视频1：角色与片段 | 组织参考、写镜头与声音 | 正文是编辑主体，素材能辨认，低频设置折叠 |
| 参考图视频2：制作与审核 | 判断候选、决定选用 | 预览/候选差异优先；进度紧凑，原文字可展开 |
| 参考图视频3：成片 | 检查完整作品 | 同共同成片框架 |
| 文生视频1：剧本与镜头 | 写声画描述 | 长正文连续阅读，不为维持三栏缩字 |
| 文生视频2：制作与审核 | 对照意图与结果 | 看片/原文方便切换，比较对象明确 |
| 文生视频3：成片 | 检查并使用作品 | 同共同成片框架 |
| 图片1：图片与编辑 | 操作画布、描述目标 | 画布与指令都可用，长指令能展开，工具按任务显示 |
| 图片2：生成与挑选 | 看细节、筛候选 | 大预览与候选条优先；对比、再生成、下载/入库就近 |
| 图片3：保存与使用 | 命名、入库、继续创作 | 所选图片与必要资料，避免再次显示全部编辑参数 |
| 接续1：视频与排序 | 排原片、选续接起点 | 轨道、当前预览和导入优先；来源按需查看 |
| 接续2：续接与挑选 | 写后续要求、判候选 | 编写时正文优先，挑选时预览优先，选用后新片段可辨认 |
| 接续3：成片 | 检查轨道导出作品 | 原顺序与输出一致，同成片框架 |
| 剧本1：故事起点 | 输入故事、图片和时长 | 故事输入为主，不让说明压缩输入区域 |
| 剧本2：剧本创作 | 阅读与修订候选 | 剧本为主，原故事可展开对照，参考按需 |
| 剧本3：资产落实 | 补资产、确认资产版剧本 | 全剧本仍可读，建议/绑定就近查看，资产长列表不夺走正文空间 |
| 剧本4：分镜设计 | 定位并修改全剧/分镜 | 保留纵向导航，当前正文优先，资产/模型针对当前对象 |
| 剧本5：片段Prompt | 核对意图、文字和素材标记 | 原段与Prompt关系清楚，有足够阅读面；原文可收起 |
| 电影1：片段生成 | 逐段生成、看片、选用 | 保留纵向分镜—片段轴，结果优先，剧本来源可跳转；不是第二个剧本编辑器 |
| 电影2：剪辑拼接 | 调顺序、拼作品 | 横向时间轴，片段操作和剧本/生成来源在下方，不复制提示词编辑业务 |

允许同一步内切换阅读/预览重点，不改变既定步骤数、生成语义、保存门与数据结构。

## 公共配置与其他页面

| 页面 | 任务与布局重点 |
|---|---|
| 制作参数 | 找到、理解、修改当前作用域字段；标签/值/解释优先，分组明确；完整模型名可查看，不固定空高度让各组一样高 |
| 全局/资产任务 | 看什么在运行、是否需处理、如何停止；对象/状态/动作先可见，日志后置 |
| 首页 | 理解并选择创作方式；用途易扫读，插画帮助辨认，海报布局不套到弹窗 |
| 项目档案 | 找到项目继续工作；名称/模式/状态/辨识图，搜索筛选优先 |
| 错误/确认/离开 | 理解对象与后果并决策；恢复路径清楚，原始错误不压过解释 |
