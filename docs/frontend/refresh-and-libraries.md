# 全站状态更新与两个库的共同体验

2026-09-09本地维护交付；静态发行号保持6.3.32，未发布。本轮不改后台数据模型、生成参数、资产原件或Prompt保存语义。

## 状态更新的实际规则

`core/snapshot-update.js`统一判定none / status / content，`contracts/project-refresh.js`声明各模式中可以单独更新的执行字段。不能仅凭revision相同跳过，因为原视频runtime、图片进度等不一定增加项目revision；也不能仅凭revision增加就重建编辑器。

- 七模式相同快照保持编辑器与草稿对象。
- 已有运行的progress、note、phase、updated等只更新对应状态区；`ui/status-region.js`逐节点更新，列表用稳定身份匹配，保留details开关与控件焦点。它仅用于状态片段，不能拿去协调有旧闭包的正文编辑器。
- 任务状态/占用改变、候选增加、正文与结构改变可能改变可用操作，继续走受保护的内容重绘。接收时复核dirty、输入焦点、弹窗、操作和播放。不能在暂缓重绘时替换正在被事件闭包引用的编辑对象。
- 原视频、图片和接续的暂缓内容保留pending标记；仅合入运行事实不表示已接收内容，解除编辑/播放保护后仍会处理该内容。
- 重绘统一经`ui/workspace-view-state.js`保存展开/关闭、滚动、焦点/选区和同一媒体节点；按项目、步骤、所选对象隔离。条目应提供data-view-key，不能以数组下标作为业务身份。保留图片原画布生命周期，进度变化不销毁画布。
- 七模式仍使用原完整项目GET和约2秒轮询，不新增增量API、WebSocket、数据库版本体系。隐藏网页暂停项目状态读取和本地时钟更新，回到可见页立即核对，后台生成不会因此停止。请求不重叠，dispose移除监听/定时器。

## 全站检查覆盖

| 页面/过程 | 现状与本轮处理 |
|---|---|
| 参考视频换人、参考图长视频、文生视频 | ProjectSession使用共同变化分类；保留原运行事实更新，替换按下标恢复details的私有实现。原生成进度、源视频准备区接入状态局部更新。 |
| 图片资产创作 | 进度变化不重建画布/输入框；完成候选仍经安全重绘。保留暂缓内容与编辑任务身份。 |
| 视频接续 | 不再仅用revision/busy判断；运行说明局部更新，轨道/候选等内容变化保留视图后重绘。 |
| 剧本、电影 | 比较已接受服务端快照；已有作业进度由共同creation-job-status呈现，正文、素材与候选变化走受保护接收。 |
| 全局任务队列 | 原5秒读取与精确停止保护保留；按任务kind/project/id更新行，不因进度刷新丢失反馈展开或焦点。 |
| 资产处理任务、上传、入库/派生进度 | 局部状态更新；任务列表按task.id匹配，避免重建整张列表；请求代次和定时器防重。 |
| 资产普通列表、详情、提示词库 | 没有周期性全页轮询。列表加载保留原筛选/路由，补请求代次、选择与视图保护；详情显式刷新保留共同视图；提示词详情按记录ID保护。 |
| 首页、项目档案、回收站、选择器 | 进入页面、显式搜索或用户动作驱动加载，没有发现定时重建页面；保留原归属检查，不添加轮询。 |
| 全局健康状态、计时器 | 原健康轮询只更新顶部状态；计时器仅更新文字，不重建工作区。 |

任务状态变化仍可能进行一次完整工作区渲染；本轮不是全站虚拟DOM改造，也不承诺任意内容更新都只改一个节点。来源等异步子面板仍按固定slot和归属响应，不把旧响应填进新槽位。

## 资产库与提示词库

两库共用`ui/library-navigation.js`和`styles/collection-navigation.css`：页头、侧栏宽度、原纸色/绿色选中态、分组标题和父子层级。原资产页散落在workbench.css中的页头/导航文字覆盖已收敛到公共归属。

资产卡片使用自适应列数和160px缩略区，不随宽屏无限放大。1902px实际窗口展示6列，原件比例保持contain；名称、媒体规格、分类与多选继续保留，列表视图仍可切换。缩略图只调整显示，不修改文件。

提示词按用途→模型分支缩进展示；当前用途与选中模型分别呈现，列表上方显示完整路径，选中条目有明确状态。进入分类会退出“全库查找”，全库查找时不保留误导性的模型选中。通用/待归类/已登记家族含义不变，不按权重变体重新分类。

资产“更多导入方式”复用scopedModal/importOptions，提供收集输出文件夹与导入素材包；调用原预览和导入过程。打开/取消不提交、不清空选择，不在页头展开挤占布局。普通导入素材入口保留。

## 检查、边界与撤回

实际结果见[证据](../evidence/site-refresh-20260909/README.md)。检查使用临时API、库和明确的状态响应替身，不读生产作品/密钥，不执行真实LLM、ComfyUI、生成或服务重载。

当前原有五模式仍保留整体体验历史登记，不能因本次定向检查通过就声明全站全部功能体验已认证。日常视觉和操作由用户反馈，不扩展压力/长时验证。

新模式必须在体验准入声明refresh、viewState、statusRegions和libraryNavigation的复用/不适用；普通库页面也按本文检查，不能另写一套状态接收或导航样式。撤回时共同入口及调用方成组核对撤回，保留本轮以前的工作树、用户数据和现有生成结果，不做整仓reset。
