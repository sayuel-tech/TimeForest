# 图片创作工作区：公共界面与制作参数

图片视觉接入沿用静态入口 6.3.2 时已认可的《图片资产创作-UI风格对齐修改报告》。V4 阶段 B 在原工作区内接入公共制作参数体验，没有重做图片工作区；当前版本、检查和交接状态只维护在[维护基线](../maintenance-baseline.md)。本文下方历史检查仍是此前证据，不代替本轮非生成检查或用户体验验收。

## 共用设计与独立业务

- 页面使用 `project-page / project-head / steps / savebar`，沿用原三个模式的标题、模式标识、步骤下划线、暖纸面板和深墨主操作。
- `workbench` 负责三栏和视口高度；`propertyTabs`、`bindWorkbench` 负责属性页签、键盘和收起。页签状态属于当前页面，不进入生成参数。
- 图片专属布局为 `image-asset-desk`，局部样式限定在 `.image-workspace`；旧参考图视频的 `image-desk` 不再被新样式命中。
- 编辑属性为素材／输入／项目。“项目”页签按原换人模式的项目属性约定编辑名称，修改进入草稿，随保存持久化。采样、种子、模型、像素面积与双图/文生图输出比例只通过右上“制作参数”调整；不再保留侧栏设置页签或重复入口。输入和运行记录分开，原始运行快照放在来源详情，错误原文可在错误提示中展开。
- 扩图的四边精确输入、目标比例和锚点位于画布工具“扩边设置”；与拖动画布边缘共用当前任务字段。画笔、擦除、撤销等继续在画布工具区。
- 连续改变比例与锚点时，几何请求未完成可使用同一任务、图A及工具的已确认工作图尺寸；切换任务或迟到响应不得复用其他图的尺寸。
- 编辑任务目录的重命名下方提供“− 废弃当前任务”，使用原ui.confirm及错误反馈。取消不保存或改画布；确认后经保存门请求废弃，切到剩余任务并清理当前候选/几何呈现。允许零任务空态，提供新增与回收站入口，不在空态调用参数或画布任务字段。后台缺task_discard_version=1或项目busy时禁用，后端仍校验归属、revision和占用。
- 任务重命名归任务目录；上传和资产库归A/B素材；候选对比和下载归当前结果；第二步在对比旁放“重新生成”，下载旁放“加入资产库”，第三步保留“继续编辑”。
- 编辑阶段主要动作是生成；挑选阶段是选定并继续，次要返回动作明确为“返回上一步”；快捷入库直接收藏当前查看候选、保留选用和步骤，成功改为已入库资产链接；使用阶段先明确选定、再保存资产，入库后才突出用于视频。保存新资产和添加版本共享一个明确的保存目标选择。
- 模型编译、生成调度、素材保护和视频业务控制器未重写。

## 代码入口

| 位置 | 责任 |
|---|---|
| `app/image-workspace-controller.js` | 图片会话、事件绑定、保存、候选/资产操作、运行状态更新 |
| `features/image-results/workspace-view.js` | 图片三步骤呈现、五工具属性、候选摘要和状态驱动动作栏 |
| `features/image-settings/index.js` | 按后端工具参数描述生成制作参数对话框，持有临时参数副本，校验并应用到当前任务草稿 |
| `core/image-catalog.js`、`app/bootstrap.js` | 校验进入工作区和刷新返回的真实 API 参数契约；旧后台明确提示前后端版本不一致 |
| `ui/production-settings.js`、`ui/error-feedback.js` | 图片／视频共用顶部参数按钮、外壳、分类与控件；错误摘要、原文展开和复制 |
| `features/image-canvas/index.js` | 图像/遮罩坐标、缩放、扩边；ResizeObserver只在适应模式自动重新适配，手动100%不被窗口变化覆盖 |
| `styles/image-assets.css` | 图片专属布局；视觉颜色来自全站变量 |

桌面给画布和指令同时留空间。窄屏任务目录折叠，展开后可重命名；动作区进入正常页面流，避免遮挡画面和正文。新增三张水彩插画继续仅用于入口和空状态，详见[美术记录](../image-assets-art.md)。

## 当前制作参数行为

右上方为唯一“制作参数”入口，直接复用视频工作区的 `productionSettingsAction` 按钮及下方工作流说明排列；图片不再覆盖该动作区的样式或并排放置重命名按钮。对话框标题明确当前图片任务草稿。公共外壳和分类顺序与视频共用；图片根据实际分支显示工作流与模型、画布与输出、采样、参考图、LoRA、高级模型组件，不展示视频时长、声音或不存在的低显存字段。完整字段描述由后端 `parameters.py` 提供，常用项与展开项分层；画布扩边精确输入仍按同一字段定义绑定。

打开克隆当前任务参数；分类切换只改变呈现。取消、关闭、Esc 丢弃弹窗编辑，保留外层原有未保存草稿及画布笔画。应用仅写回当前图片任务草稿，再由“保存草稿”持久化；生成时仍自动保存。刷新模型目录不应用参数、不重建画布。“恢复默认”读取当前工具公开字段对应的后台 defaults/models（模型含网站 image_models 配置），包含种子及适用的扩边等高级参数，只改弹窗临时副本。取消可撤销；应用后再由保存草稿持久化。不改原图、指令、遮罩、其他工具未公开字段或历史候选；缺少任一默认值时整体拒绝，不补造前端默认值。原四编辑工具及文生图、候选挑选、入库和视频引用继续使用原流程。

种子分为“每次随机／固定种子”，固定 0 有效；小数、负数、非法字符串及超出安全整数范围时保留输入并反馈，不能静默截断或变成随机。展示的上次种子取当前任务实际运行记录。底模、图文编码器（CLIP）及图片 VAE 与视频同类字段使用 `select`；LoRA 与视频槽位同样使用可输入的 `datalist`。使用目录提供的完整相对文件名；不在目录中的底模／编码器／VAE 以“目录未发现，保留当前选择”标识原项，LoRA 也显示目录未发现提示，不自动回默认。

“刷新本地模型列表”使用本机文件扫描；“同步节点能力”单独说明需要引擎在线。远程引擎显示对应地址的缓存来源及更新时间，不混入本机目录。刷新或同步失败保留参数和现有目录信息，显示真实反馈。图片保存／请求／运行错误使用摘要与可展开、可复制原文，节点与字段信息只展示实际收到的内容。

图片工作区打开前、参数临时副本建立及目录刷新时，检查实际 `GET /api/v5/image-projects/catalog` 返回的 `parameter_contract_version=1` 与原四工具字段描述，声明或使用text时另核对文生图能力与字段。旧网站进程只加载了新静态文件、仍返回旧参数目录时，显示前后端版本不一致及重启网站服务的提示，不以空分类窗口假装参数已加载。刷新中的契约失败不会替换已有目录或参数；保存已有编辑后重启网站再刷新，无需启动 ComfyUI。

详细绑定只维护在[参数映射](parameter-map.md)，公共行为见[统一参数与交互契约](parameter-and-interaction-contract.md)。同用途新工作流仍走[工作流适配契约](../governance/workflow-evolution-contract.md)；本次未增加第二图片工作流或改变默认生成语义。真实生成、模型组合、画质与最终用户体验仍待用户验证，不能由隔离页面或编译检查代替。

上述单一入口、项目属性与画布扩边位置是当前修正后的代码行为；本段不把下方历史页面记录当作这次修正的浏览器验收。最新实际检查及待用户体验项以维护基线记录为准。

## 历史隔离检查

- 图片1280×720：底部动作下沿707.5px，指令下沿608.5px，位于工作面内部。
- 700px：无页面横向溢出、任务目录折叠、动作区不覆盖内容。1920px：画布空间增长且图片自动适配，手动缩放保留。
- 属性方向键、收起/展开不修改草稿；四工具切换、双图缺B提示、扩图拖动及隔离草稿实际保存通过。
- 候选对比→选定→保存目标切换→入库后视频入口，以及空、等待、失败状态用隔离响应检查通过。没有真实生成或真实候选质量测试。
- 原三个模式：关闭/开启新图片样式后，三栏、面板间距、输入字号和高度相同。换人/参考图使用现有项目只读查看；文生使用只读参考数据适配的页面，未写生产数据。
- 相关JS语法与差异格式检查通过；页面无脚本错误，检查过程生成请求数0。

检查材料和临时服务配置统一存于 `<本地维护归档>`，不放入正式资源目录。临时服务使用隔离数据、禁用生成且引擎地址不可连接。所有ComfyUI生成测试均未运行。

设计依据以现行[前端规范](README.md)、[新增模式规范](adding-a-mode.md)及其引用的V3实施记录为准。后续扩展继续组合这些组件，不单独再造步骤导航与属性面板。

## 文生图工具接入

同一五工具栏追加text；无图任务的第一步只展示画面描述、输出尺寸与原操作栏，不创建ImageCanvas或要求上传素材。原四工具的画布/属性保持。跨text和编辑工具总是通过原任务创建及保存门建立独立任务，保留原素材、笔画、参数和候选；不做隐式转换。候选阶段沿用重新生成/入库/保存与使用，仅省略对比原图。

创建text及打开含text任务的项目需catalog.text_to_image_version=1和parameters.text；旧四工具目录仍可用于旧项目，缺文生图能力时明确提示更新服务。按当前工具missing_by_tool显示节点缺口。制作参数快速取消再打开时忽略上一弹窗延迟送达的close事件，保留新副本。
