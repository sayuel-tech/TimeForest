# 时间森林当前维护交接

## 当前版本 v6.3.32

本版在 v6.3.20 上汇总 6.3.21～6.3.32 的五模式公共体验、资产生命周期与派生追溯、统一提示词库。功能范围及升级注意事项见[更新日志](../CHANGELOG.md)，代码与 GitHub Release 配套包见[分发说明](release-distribution.md)。

当前五模式为参考视频换人、参考图长视频、文生视频、图片资产创作和视频接续。统一提示词库按用途／模型家族组织，保存项目成功后自动收录，支持固定内容版本、明确字段应用、分类管理与独立备份。剧本／LLM 仅预留接入契约，并未实现相应创作页面或调用。

## 检查与边界

本版开发阶段完成相关隔离保存／引用／来源／派生／参数检查；提示词库八项后端用例及 1280/760 两种宽度的五模式操作通过，公共体验准入十项用例通过。发行另外核对公开内容、20文件配套包清单与哈希、七份离线 API 编译及源码与配套组合的必要回归。

不把真实生成、大文件断网续传、大型资产库、长期多窗口或整体审美视为已穷尽验证，交给使用反馈。发行不启动 ComfyUI、不生成或试模型组合、不改用户数据、不安装升级环境。

六份来源工作流与 v6.3.20 相同，配套包不含权重。升级前备份配置、项目、外部资产库和提示词库；源码回退不能回退作品。新工作流和新模块继续遵守现行参数、资产和提示词契约，不凭名称猜模型家族。
