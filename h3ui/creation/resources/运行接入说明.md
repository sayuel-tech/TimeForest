# TimeForest 剧本与电影配套（V3.0 执行版）

本目录是程序读取的运行资源和静态配套，不包含密钥、模型权重、用户项目或生成结果。版本 V3.0 是实施方案号，不替代网站发行号。

`运行模板/common.txt` 与任务 TXT、对应 JSON schema 一起由服务器组装为 system 消息；用户故事、固定参考与允许引用形成 user 请求上下文。附件执行计划与维护 AGENTS 不会作为模型指令发送。全部 12 个响应合同先校验，再进入候选；只有明确应用才写入正文。完整响应格式不合法时可另发一次显式格式修复，不自动修复，不从截断响应补写内容。

初始 model_id：`deepseek-v4.1-flash-expires-on-0910`。这是可编辑临时配置；调用效果、额度和视觉支持未在本轮验证。错误不触发备用模型。服务密钥在网站设置中单独保存，不编辑本包。`配置样例` 中的本地/未来 Provider 只用于表示接口，网站会拒绝本轮尚未实现的 Provider 操作。

电影只接现有 H3 的跳舞与官方图片工作流。实际 profile 在 `h3ui/creation/movie.py` 的 `PROFILE_RECIPES`，由原 Recipes 编译；不把资料包中的示意 profile 名称当成已适配工作流，也不改变原默认采样。外部续接准备 22 帧视频与对齐声音，不伪称原内部二采 latent 续接。

`API契约/runtime-routes.json` 是本轮实际路由清单。原 OpenAPI/请求与响应 schema 保留作为核心契约资料；原站公共 `/projects` 快照和 `/movie/catalog` 沿用原生扩展，以 `docs/creation-modes.md` 的适配说明为准。新任务/准备结果不返回内部编译图或输入磁盘路径。CreateExport 的 `accepted_seams` 是本轮补齐接点确认的兼容扩展。

`离线样例/LLM` 是固定 fake 测试资料，不是模型实测结果。`美术配套` 包含规格、实际提示词和成品清单；五张插画已在独立授权后制作，WebP在仓库static/assets对应路径，母稿在docs/art-masters/creation-v3，配套归档保留同样路径。网站与配套需共同保存，普通开发不自动发布。
