# 参考画面创作模板

> V2.9：本文件为可读设计说明。未来运行读取 `运行模板/` 的对应纯TXT，任务/Schema/正文取值以 `配套清单/llm-task-registry.json` 为准；原“字段未定”说明不覆盖新合同。未进行模型实测。

**任务：reference_image｜由剧本带入现有图片模式**

## 输入

分镜与片段的创作内容、图片用途、确认的角色与场景资料、当前图片工具能力、实际可提供的输入图及编号，以及用户要求。

## 给模型的任务草案

```text
为指定用途准备参考画面的制作要求和当前图片工具可用的文案。依据已确定的片段，不重新设计剧情。

起始参考只表达起始瞬间，结束参考只表达结束状态，中间关键状态则表达用户指定的时刻。不要把走路、停下、低头等多个时间阶段同时挤成一张画面。

明确构图、人物关系、视角、姿态、光线及需要保持的身份或服装要素。场景中的声音只有影响可见表演时才转为画面描述，不要求图片生成“播放声音”。

只使用实际工具允许的输入组合和标签。H3 视频 Prompt 不是图片 Prompt，不直接照搬视频时序、尾部上下文和音轨要求。

返回候选文案与用途说明，不生成图片、不宣布回填成功。需要改变故事才能成立时，将问题留给用户，不偷偷改分镜。
```

## 建议 payload

`image_prompt_text`、`reference_purpose`、`used_reference_keys`。制作要求可用另一个明确的文字字段呈现，但不应重复产生两份相互不一致的图片 Prompt。

图片实际调用字段与当前工具适配一致；这里不冻结具体模型或 API。工具只能使用少量输入时，由用户明确取舍，不默默丢掉角色参考。

## 模式往返

网站保存源剧本、稳定目标、内容版本和用途。用户在图片模式生成、挑选、入库后，再选择绑定回原目标；目标已经变化时保留图片，重新确认绑定，不写入相邻片段。

## 继续打磨

参考制作要求与最终图片文案是否分别显示、回填时默认替换还是追加备选，可继续结合现有公共图片体验讨论。
