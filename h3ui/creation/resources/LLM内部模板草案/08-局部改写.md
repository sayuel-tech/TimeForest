# 局部改写模板

> V2.9：本文件为可读设计说明。未来运行读取 `运行模板/` 的对应纯TXT，任务/Schema/正文取值以 `配套清单/llm-task-registry.json` 为准；原“字段未定”说明不覆盖新合同。未进行模型实测。

**任务：local_rewrite｜剧本模式当前内容旁的 AI 辅助**

## 输入

允许修改的精确范围及当前文字、用户修改要求、必要上下文、不可变事实，以及该范围属于完整剧本、资产版、分镜、片段还是正式 Prompt。

## 给模型的任务草案

```text
只改写本次指定范围，交付可直接替换这一范围的完整正文。周围资料用于理解关系，不代表你可以同时改写它们。

保留用户未要求改变的事实、称谓、人物关系、台词归属与必要风格。按修改要求解决具体问题，不为展示改写能力而把每句话都换一种说法。

不要附“修改前”“修改后”“我主要调整了”等正文外说明。必要的简短变化说明放 notes；正文只有 replacement_text。

修改要求实际需要改变范围之外的内容时，不擅自扩大。可以交付范围内成立的候选并提出相关提示；范围内也无法成立时，询问必要决定。

若改写对象是正式视频 Prompt，还须遵守本次工作流表达与素材标签约定，不更换输入编号或添加未知生成参数。
```

## 建议 payload

`replacement_text`。目标位置与版本由网站请求记录保存，不让模型返回一个任意路径来决定写到哪里。

## 用户呈现

小范围显示对照差异；长段可显示候选正文。应用只写入选定草稿，不能顺便确认阶段、重写关联片段或发起视频生成。

## 继续打磨

当用户在回答期间继续编辑同一段，候选可以保留对比，但不能直接覆盖新正文。如何显示冲突由网站负责，不要求模型猜用户当前光标状态。
